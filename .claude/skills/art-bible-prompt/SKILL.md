# Art Bible 提示词注入

为《九陆纪元》角色图/场景图/视觉设计卡片生成图片提示词时，必须遵守以下全部规则。
这些规则来自项目 Art Bible，不可省略、不可替换、不可"简化"。

## 1. 风格锚点句（每条提示词开头必带）

```
干净半写实东方幻想漫剧插画，电影级高特效动作关键帧，柔和漫射光，清晰主体，低描边
```

> 风格锚点句是全局句，永远不放具体画面元素（如"蓝白魔法阵与赤金龙焰对撞"）。
> 具体画面元素只写在各卡自己的提示词正文里。

## 4. 配色权重（每张图提示词必带，选对应类型）

句式：`配色权重：<主色>约N%主导，<次色>≤M%仅限<范围>，<点缀色>仅作<范围>；冷暖不均分，单一主光源定基调`

| 类型 | 适用情绪 | 配色 |
|------|---------|------|
| 暖主导 | 高燃/爽/奇观 | 暖赤金80% / 冷蓝≤20%限净化光束与数据流 / 金绿限世界树光丝 |
| 冷主导 | 压迫/危/净化压境 | 净化冷蓝70% / 暖赤金30%限熔浆余烬反光 |
| 金绿型 | 世界树戏 | 金绿60% / 暖赤金25%环境余光 / 冷蓝≤15%限数据流 |
| 云海型 | 升空/结尾 | 金色阳光80% / 云影冷灰≤20% / 不出现净化冷蓝 |

## 5. 正向约束词（每条提示词结尾必带）

```
画面干净无描边，无墨线，无裂纹，无草稿线，无脏黑边，无死黑阴影，无文字水印，保持角色一致性，服装不漂移。保持面部一致，无变形，无拉伸，避免抖动运动和弯曲肢体，面部清晰，人体结构正常，动作自然流畅，画面稳定，竖屏9:16，电影质感
```

## 6. 禁止清单（违反即重写）

- 黑色粗描边/墨线
- 宫格分镜
- 死黑阴影
- 裂纹划痕纹理
- 文字水印签名
- 草稿线辅助线
- 负向提示词（Seedance 不读，写了等于浪费）
- "快速"/"fast"（会导致运动模糊）
- 多运镜叠加（每镜只一个）
- 超 6 秒单段（角色变形）
- 风格锚点句里混入具体画面元素

```

[正向约束词]

```

### 场景概念图

```
[风格锚点句]。
[场景ID对应的完整光影特征描述]，无人物，纯场景概念图。
[前景/中景/后景具体元素]。
[正向约束词]
配色权重：[按场景情绪选择]
```

### 角色+场景合图（视觉设计稿）

```
[风格锚点句]。
[角色视觉DNA] 站在/位于 [场景描述]。
[具体姿势/动作]，[景别]。
[场景光影特征]。
[正向约束词]
配色权重：[按情绪选择]
```
