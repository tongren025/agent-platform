# Seedance 2.0 / 即梦 提示词生产手册（完整版）

## 一、七要素图片提示词公式
1. 风格/画风：干净半写实东方幻想漫剧插画 / 电影级高特效动作关键帧
2. 主体描述：角色视觉DNA（发型+瞳色+伤疤+服装+道具），每次必须完整重复
3. 动作/表情：身体部位级动作 + 表情关键词（眉头紧皱/牙关咬紧/瞳孔映光）
4. 景别与构图：七大景别 + 机位角度
5. 光影与质感：具体光源类型 + 方向 + 色温
6. 情绪氛围：情绪关键词 + 氛围元素（雨/烟尘/粒子/体积光）
7. 画质后缀：正向约束词

## 二、八层 Seedance 视频结构
1. 素材角色声明：@图片/@视频/@音频引用 + R1/R2编号锁角色
2. 镜头标签：「镜头1」「镜头2」分段，每段≤6秒
3. 景别与主体：景别 + 2-3个静态特征（具体名词）
4. 动作：身体部位级 + 幅度 + 速度，优先慢速连续小动作
5. 运镜：每镜只一个运镜，中英双写如「缓慢推进(dolly in)」
6. 场景与光影：环境 + 光源方向/色温 + 氛围元素（质量ROI最高）
7. 音频：对话/音效/环境音（Seedance 2.0 原生音画一体）
8. 全局收尾：风格锚点 + 正向约束词 + 质量后缀
底层逻辑 S-A-C-S-C 不变，八层是生产展开。

## 三、致命规则
- Seedance 2.0 不读负向提示词！只用正向约束词
- 「快速」「fast」是禁止词 → 运动模糊
- 纯中文效果最稳（运镜术语中英双写除外）
- 每段≤6秒 → 超过角色变形
- 镜头运动和角色动作分开描述
- 每镜只一个运镜动作
- 角色描述每次完整重复

## 四、七大景别 × 情绪
| 景别 | 情绪 | 搭配 |
|---|---|---|
| 大远景 | 渺小/孤独/命运 | crane down |
| 远景 | 空间/格局 | tracking |
| 全景 | 客观建立 | static |
| 中景 | 对话/日常 | dolly in |
| 近景 | 情绪 | dolly in |
| 特写 | 高情绪 | static+震动 |
| 微距 | 奇观 | dolly in |

## 五、50运镜速查（常用20）
推拉：dolly in / dolly out / zoom in / zoom out
横移：tracking / truck left·right / arc shot
升降：crane up / crane down / boom up / boom down
旋转：pan left·right / tilt up·down / dutch angle / 360 orbit
特殊：static / handheld / whip pan / bird's eye / low angle

## 六、光影速查
伦勃朗光=压迫戏剧｜逆光/轮廓光=神秘孤独｜底光=恐怖不安｜顶光=审判神圣｜双色温=冲突对峙｜体积光=史诗希望｜环境/柔光=日常温柔

## 七、运镜情绪组合拳
dolly in+浅景深=世界只剩这个东西｜crane down+雨=命运降临｜static+寂静=最痛没声音｜tracking+背影=你跟不上｜whip pan=时空转换｜dutch angle+底光=世界崩塌

## 八、角色一致性三视图工作流
1. 三视图母版（正/侧/背），@图片1共用
2. 视觉DNA 5-8个固定词，每镜完整带上
3. 双重约束：新场景 → DNA完整复述 + @cref引用母版
4. 视觉符号每镜必写（苍霖左脸疤/胸口碎片）

## 九、@引用系统
@图片1-9角色/背景/首帧，@视频1-3运镜/动作/风格（最强风格锁定），@音频1-3配音/BGM。总计≤12，最优4-5个。关键句「画风动作严格对齐@视频1的风格」。

## 十、平台规格
输出4-15秒/次，最高2K，创意度0.4-0.6，参考强度0.6-0.85。竖屏：前3秒炸点，单句≤10字，单镜3-8秒，结尾5秒钩子。工业化：母版图→风格视频锁@视频1→10核心场景→每镜批量10+张。
