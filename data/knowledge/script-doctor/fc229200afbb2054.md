# 剧本体检判据 · 《九陆纪元》世界观红线与第一季设计

## 一、故事内核（最高红线）

**「没有人选你。但你还是站起来了。」**

被世界删掉的人，最后去修复世界。主角不是被选中的，是被打到泥里自己爬起来的。

**红线（违反即最高优先级标注）**：
- 禁止"觉醒/天命/血统开挂"叙事——第一季专门设计了"世界树光丝被暴徒掐灭"来粉碎天命套路
- 主角的成长只来自选择和经历，不来自天赋激活
- 不打脸、不逆袭爽文式碾压——我们只是不放手

## 二、第一季三幕结构（苍霖线，10 集）

- 第一幕「活着」（EP01-03）：巷子打斗 → 假觉醒被掐灭 → 艾拉救场 → 龙蛋
- 第二幕「成长」（EP04-07）：养龙蒙太奇 → 苹果反转喜剧 → 青鸾数据残留（跨陆钩子）→ 世界树信号
- 第三幕「出发」（EP08-10）：选择离开烬龙陆 → 骑龙升空 → 九大陆剪影

## 三、10 集情绪曲线（点评单集时对照本表）

| EP | 情绪弧 | 嘴替台词锚点 |
|----|--------|---------|
| 01 | 暗→更暗→微光（碎片激活） | 无台词，纯视觉冲击 |
| 02 | 暗→炸亮→崩塌→**更暗**（最低谷1） | "也是。"（自嘲接受，第一次） |
| 03 | 暗→冷→转折→暖 | "你的血流到样本上了。" |
| 04 | 暗→暖→**温暖峰值**（最高点1） | 幼龙拱入怀，无需台词 |
| 05 | 暖→欢乐→暗线（唯一纯喜剧集） | 第一次笑（苹果喜剧） |
| 06 | 安宁→惊醒→悬疑 | 全息求救信号（跨陆钩子） |
| 07 | 敬畏→恐惧→自欺（最低谷2） | "不是我们的事。" |
| 08 | 不舍→对话→决然 | "也是。"（老矿工释然，第二次） |
| 09 | 紧张→恐惧→**自由峰值**（最高点2） | 坠落→展翅→飞 |
| 10 | 好奇→敬畏→渺小→安静收尾 | "好大……" |

**结构要点**：EP02/EP07 两个最低谷；EP04/EP09 两个最高点；EP10 安静收尾不是高潮收尾。
**"也是"贯穿线**：EP02 苍霖自嘲 → EP08 老矿工释然。同样的词，六集成长后完全不同的重量。点评 EP02/EP08 时必查这条线是否成立。

## 四、核心角色目标参照（查"角色目标丢失"用）

- **苍霖**：弧光 = 从「活着」到「为别人活着」。前期懒散欠揍是保护色
- **艾拉**：冷淡精确，救人像处理麻烦事，不解释不安慰——她的台词绝不能变暖变多
- **巨龙**：外凶内萌（扑苹果、小口啃皮、委屈巴巴）；它是情绪调节阀，不是战斗力外挂
- **老矿工**：EP08 的"也是"承接者，代表留下的人的尊严
