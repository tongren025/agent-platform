# 好莱坞编剧方法论 — 核心知识库

## 一、三幕结构（Three-Act Structure）

所有好莱坞大片的骨架：

### 第一幕：建置（Setup）— 占全片 25%
- **开场画面**：定义故事的视觉基调和世界观
- **主角登场**：用一个能体现核心性格的动作介绍主角（不是旁白！）
- **日常世界**：展示主角的"平凡生活"，让观众产生共鸣
- **激励事件（Inciting Incident）**：打破日常的那件事。《黑客帝国》= Neo 收到 follow the white rabbit；《盗梦空间》= Saito 提出 inception 任务
- **拒绝与接受**：主角犹豫 → 被迫或主动踏上旅程
- **第一转折点**：主角做出不可逆的决定，进入第二幕

### 第二幕：对抗（Confrontation）— 占全片 50%
- **试炼与盟友**：主角结交盟友、学习新技能、遭遇小挫折
- **中点逆转（Midpoint）**：假胜利或假失败。《复仇者联盟》= 团队首次集结成功（假胜利）→ 神盾局母舰被袭（真危机）
- **反派升级**：反派展现真正实力，代价升高
- **一切崩塌（All is Lost）**：主角遭受最大打击。导师死亡/队友背叛/真相揭露
- **黑暗时刻（Dark Night of the Soul）**：主角内心最低谷
- **第二转折点**：主角找到新的力量/真相/决心

### 第三幕：解决（Resolution）— 占全片 25%
- **集结与冲刺**：主角带着新领悟发起最终行动
- **高潮（Climax）**：正面对决。要求主角用第二幕学到的东西才能赢
- **结局画面**：与开场画面呼应，展示主角的成长

## 二、Save the Cat! 节拍表（Blake Snyder Beat Sheet）

更精细的 15 个节拍：

1. **开场画面** — 定基调（"before" 状态）
2. **主题陈述** — 第5分钟左右，某角色说出主题（主角此刻不理解）
3. **铺垫** — 展示主角的世界、缺陷、需求
4. **催化剂** — 改变一切的事件（第12分钟）
5. **争论** — 主角犹豫要不要行动
6. **进入第二幕** — 主角做出选择
7. **B故事** — 爱情线/友情线启动（通常是帮主角成长的人）
8. **乐趣与游戏** — 预告片素材都在这里，"承诺的前提"
9. **中点** — 假胜利或假失败，代价升高
10. **反派逼近** — 外部压力 + 内部团队裂痕
11. **一切崩塌** — 最大的失败
12. **灵魂黑夜** — 反思与觉醒
13. **进入第三幕** — 灵感闪现/找到方案
14. **终场** — 执行计划，高潮对决
15. **结尾画面** — "after" 状态，与开场呼应

## 三、角色弧光（Character Arc）

### 正向弧光（最常见）
缺陷 → 挑战 → 觉醒 → 成长
- 《疯狂动物城》：Judy 从天真理想 → 经历偏见 → 理解复杂性 → 真正的正义

### 负向弧光（悲剧/反英雄）
优点 → 腐蚀 → 堕落
- 《绝命毒师》：Walter 从好老师 → 权力上瘾 → 变成自己最恨的人

### 平坦弧光（主角改变世界）
主角信念不变，但改变了周围的人
- 《肖申克的救赎》：Andy 的希望从未改变，但他改变了整个监狱

### 角色弧光公式
**外在目标**（想要什么）≠ **内在需求**（真正缺什么）
- 外在：找到宝藏 / 打败boss / 赢得比赛
- 内在：学会信任 / 接受自己 / 放下执念
- 高潮时刻 = 主角为了内在需求而放弃外在目标

## 四、对白写作法则

### 潜台词（Subtext）
角色从来不直接说他们真正的意思：
- ❌ "我很害怕" 
- ✅ "你觉得这条路安全吗？"（表面问路，实际表达恐惧）

### 每个角色有独特的说话方式
- 用词习惯（文绉绉 vs 口语化）
- 句式长短（军人短句 vs 学者长句）
- 口头禅/口癖
- 信息量（话多 vs 惜字如金）

### 对白的隐藏功能
每句对白至少完成两个任务（否则删掉）：
1. 推进剧情 + 揭示性格
2. 制造冲突 + 传递信息
3. 建立关系 + 暗示伏笔

### 对白的节奏
- 紧张场景：短句、打断、沉默
- 温情场景：长句、停顿、未说完的话
- 喜剧场景：误解、反转、callback（呼应前面的梗）

## 五、场景写作原则

### 进晚出早（Enter Late, Leave Early）
每个场景从冲突已经开始时进入，在高潮刚过就切走。不需要"你好""再见"。

### 每个场景必须有冲突
无冲突 = 无场景。冲突不一定是打架——可以是：
- 目标冲突（两人想要不同的东西）
- 信息不对称（观众知道炸弹在桌下，角色不知道 = 悬念）
- 内心挣扎（应该做的 vs 想做的）

### 场景转换要有因果链
场景A的结果 → 引发场景B的原因
不是 "然后...然后...然后..."
而是 "因为...所以...但是..."

## 六、漫剧特殊技巧

### 视觉叙事优先
漫剧是视觉媒介，遵循"画面能说的不用对白说"：
- 角色心情 → 用表情和肢体语言，不用旁白
- 时间流逝 → 用光影变化/季节变化的画面
- 关系变化 → 用角色之间的物理距离

### 分镜友好的剧本写法
每个场景描述要包含：
- 画面可以捕捉到的具体动作（不是"他很难过"，是"他攥紧了拳头，指甲陷入掌心"）
- 关键物件的特写提示（"桌上的咖啡已经凉了，杯壁挂着干涸的咖啡渍"）
- 光影和色调提示（"逆光，人物只剩剪影"）

### 每帧都是构图
好的漫剧每一帧单独截出来都是好画面：
- 主体突出（角色占画面1/3到2/3）
- 视觉引导线（引导目光到关键位置）
- 前中远景层次分明

## 七、经典结构模板

### 复仇型
受害 → 觉醒 → 训练 → 追踪 → 对决 → 代价

### 成长型
平凡 → 发现天赋 → 导师 → 试炼 → 失败 → 领悟 → 证明自己

### 悬疑型
日常异常 → 调查 → 假线索 → 真相碎片 → 反转 → 真相大白 → 余味

### 爱情型
相遇 → 火花 → 阻碍 → 误会 → 分离 → 领悟 → 重逢
