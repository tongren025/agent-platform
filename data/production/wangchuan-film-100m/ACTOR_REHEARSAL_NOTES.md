# 《忘川剑》演员排练手册

**对应剧本：V3 观众体验修订稿｜目标片长：100分钟**

这不是人物小传的重复，而是排练时可以直接使用的“行动谱”。每场不要先决定情绪，先完成任务；
情绪是任务受阻后留在身体上的结果。

## 一、全组共识

1. **不演时间穿越。** 看见未来的震动，落实为核对证据、怀疑对方、保护东西或寻找出口。
2. **不演宏大牺牲。** “全城”必须落到一张脸、一个名字、一双正在松开的手。
3. **同一个陆沉，不同的用力方式。** 年轻陆沉先动手再判断；老陆沉先删掉无效动作，只在失控时变回年轻人的打法。
4. **停顿必须有任务。** 不是空白地难过，而是在忍住一句话、确认一个名字、决定是否松手。
5. **失忆不是发呆。** 身体保留习惯，头脑失去解释；结尾托住孩子后颈，就是最重要的失忆表演。

## 二、人物秘密的知情进度

| 人物 | 开场相信什么 | 中段被迫承认什么 | 结尾真正做到什么 |
|---|---|---|---|
| 陆沉 | 只要由我接管，就不会失去家人 | 每次灾难里不变的那一步是自己 | 让别人选择，并承担无法记住女儿的余生 |
| 老陆沉 | 杀掉年轻自己或抢走剑就能阻止一切 | 自己仍在用暴力替别人做决定 | 和年轻自己共同松开小满 |
| 苏照 | 证据和分工能阻止悲剧 | 正确方案也不能保证女儿活下来 | 不替陆沉选择，但完成让全城归名的行动 |
| 小满 | 父亲只要回来就会答对应暗号 | 父亲会犯错，也可能听见她 | 把父亲从“只救我”推向“带他们回家” |
| 裴九思 | 只要重来，关门之罪便能消失 | 剑给的是服从自己的回声，不是儿子 | 亲手开门、归还记忆，并活着认罪 |
| 秦野 | 陆沉总能收拾残局 | 陆沉也可能是最大的风险 | 不等英雄，和普通人一起开闸自救 |

## 三、关系温度

- **陆沉—苏照**：不是“感情破裂”，而是苏照拒绝再被保护之名排除在决定之外。两人的和解不是拥抱，是第39场共同拉绳、第51场共同接住孩子。
- **陆沉—小满**：开场父亲把女儿当需要防守的软肋；小满不断要求成为有判断力的队友。暗号是一份女儿有权叫父亲停下的契约。
- **陆沉—老陆沉**：表面是猎物与猎人，实际是一个人逼另一个人承认“我会失败”。两人的亲近不能温暖，直到第38场第一次交出剑。
- **陆沉—裴九思**：裴九思不把陆沉当敌人，而当最有可能理解自己的同类。每次劝说都应像递一把椅子，而非挥一把刀。
- **苏照—老陆沉**：她看见的是一个失去女儿又失去自己的丈夫，但不允许这份怜悯削弱判断。第46场询问未来，是她唯一一次允许私人问题先于任务。

## 四、逐场行动谱

| 场 | 主行动 | 障碍与手段 | 场尾变化 |
|---:|---|---|---|
| 1 | 老陆沉要确认自己还记得为何回来 | 靠木鞘认人，假装记得老妇 | 刻下小满，踏入回声门 |
| 2 | 陆沉要夺回武器和局面 | 试探、反制、观察同一伤疤 | 老陆沉停刀，陆沉带剑逃走 |
| 3 | 陆沉要甩掉追杀者 | 用自己的惯用陷阱测试对方 | 拔剑一寸，亲眼看见代价 |
| 4 | 秦野要判断陆沉还能否带队 | 用证物和冷笑话逼他回答 | 陆沉发现错过女儿生日 |
| 5 | 陆沉要让苏照重新收留并协助自己 | 把婚姻问题转换成案件 | 苏照拒绝替他回避旧账 |
| 6 | 小满要确认眼前的人是不是父亲 | 暗号、私密问题、拒绝拥抱 | 陆沉靠观察而非记忆答对一半 |
| 7 | 裴九思要陆沉主动交剑 | 恐惧、权威、父亲之死 | 陆沉因控制欲拒绝交出 |
| 8 | 陆沉要从幸存者口中取得真相 | 追问伤口与现场 | 苏照找到被篡改记忆的证据 |
| 9 | 苏照要终止两个陆沉的互杀 | 利用旧伤和共同秘密 | 玉佩合拢，身份无法再否认 |
| 10 | 陆沉要逼未来自己交代结果 | 控武器、缩短问题、挥拳 | 得知自己为小满拔剑 |
| 11 | 陆沉要从裴九思和老陆沉中选暂时可信者 | 看谁害怕对方说话 | 第一次违抗官方追捕 |
| 12 | 老陆沉要让年轻自己看见名字的重量 | 用木鞘压剑，承认忘记小满 | 陆沉对未来的自己产生恐惧 |
| 13 | 老陆沉要迫使陆沉说出会先选女儿 | 复述灾难，不替他总结 | 陆沉毫不犹豫重走第一步 |
| 14 | 陆沉要证明老陆沉是幻觉 | 私密伤疤、出生问题、行动方案 | 老陆沉指出唯一不变的是陆沉 |
| 15 | 苏照要收走会放大陆沉执念的剑 | 让他为“换谁”指出具体名字 | 陆沉第一次暂时松手 |
| 16 | 三人要确认失忆扩散速度 | 用具体病人测试未来描述 | 陆沉看见代价不是抽象数字 |
| 17 | 苏照要找到父亲研究的真实用途 | 敲木鞘、拼图、读工记 | 木鞘被识别为还忆钟槌 |
| 18 | 秦野要带出裴九思罪证 | 装杂役、开锁、用玩笑抗压 | 他发现北渠和钟楼都被布雷 |
| 19 | 裴九思要让替身继续做儿子 | 用旧物和问题校准少年 | 少年要求停止扮演裴安 |
| 20 | 老陆沉要让两人相信未来代价 | 用伤口中的记忆碎片重放自己松开钟绳的错误 | 苏照拿回未来工记主动权 |
| 21 | 苏照要找出关闭回声门的条件 | 拼合两半工记，逼老陆沉承认失败 | 目标从“封剑”变成“主动放下” |
| 22 | 小满要让父亲正式承诺会听她叫停 | 木燕、纸条、不给空头保证 | “燕子回家”成为行动契约 |
| 23 | 苏照要让混乱百姓先保住姓名，小满要保护同行孩子 | 苏照给简单指令；小满识破假钟号并沿路画缺尾燕子 | 普通人开始自救，小满留下可追踪路线 |
| 24 | 陆沉要把所有问题重新分配出去 | 下命令、分路线 | 老陆沉看出他仍优先安排女儿 |
| 25 | 苏照要拿回缺失钟律 | 查血字并约束老陆沉杀意 | 老陆沉为散落名字停下追击 |
| 26 | 秦野要让被控制的人恢复自主 | 喊名字、换打法、自己钻齿轮 | 无名少年第一次拒绝裴安身份 |
| 27 | 陆沉要沿女儿留下的路找她，并看懂三日前自己的选择 | 缺尾燕子、被打开的木燕暗槽、记忆机关 | 他不能再把失败归咎于预言 |
| 28 | 两个陆沉都要证明自己才真正爱小满 | 互揭对方的逃避方式 | 老陆沉说出陆沉最怕的是“不够用” |
| 29 | 苏照要救出全部孩子而非只抱走女儿 | 烧掉未来答案，把带路交给小满 | 母女成为并肩行动者 |
| 30 | 裴九思要招募陆沉成为同谋 | 门钥匙、自己的罪、取消二选一的诱惑 | 陆沉开始动摇但不拿钥匙 |
| 31 | 陆沉要夺走能决定未来的工具 | 质疑双方影像、合剑入鞘 | 他打中老陆沉旧伤后独自离开 |
| 32 | 老陆沉要让年轻自己第一次看不懂未来 | 改变十九年前的剑路 | 陆沉宁可抓剑也不抓求救的手 |
| 33 | 老陆沉要把小满真实遗言送到过去 | 用细节逼陆沉听完 | “带他们回家”第一次出现 |
| 34 | 苏照与秦野要让全城按分工行动 | 名字对抗铜哨，白线引导孩子 | 七号钟缺响，记忆无法送回 |
| 35 | 小满要补回七号钟并测试父亲是否记得承诺 | 自己爬梯、主动问暗号 | 父亲答对，东翼随即坍塌 |
| 36 | 秦野要开闸且不让无名少年替别人死 | 借姓名牌、自己入齿轮 | 少年用“秦野”把他从水里拉回 |
| 37 | 陆沉要证明自己能在三下内搬开石头 | 肩顶、剑撬、用承诺压住恐惧 | 小满用暗号叫停他 |
| 38 | 陆沉要同时救女儿与停钟 | 第一次把剑和任务交给老陆沉 | 裴九思夺剑，全城开始失名 |
| 39 | 父母要让小满撑到石头抬起 | 私密问题、共同解红绳 | 小满把城外的人交给父亲后死亡 |
| 40 | 陆沉要否认眼前的死亡 | 剑中声音提供一条可行动的路 | 他握剑并再拔半寸 |
| 41 | 剑中回声要让陆沉留下 | 面、完整家庭、取消责任 | 无红绳和无药渍暴露完美的虚假 |
| 42 | 裴九思要把裴安留在怀里 | 回声重复最顺从的台词 | 他第一次松开“儿子” |
| 43 | 老陆沉要让年轻自己看见永恒团聚的空洞 | 不会减少的面、墙外断掉的名字 | 陆沉得知同一灵魂的两个自己都会遗忘小满 |
| 44 | 苏照要让还忆钟具备最后一响 | 用刀逼问簧片，不提供宽恕 | 裴九思装回簧片并接过公开指挥 |
| 45 | 全城普通人要把姓名送回钟楼 | 互相报名字、借名字 | “归还”第一次大于主角个人选择 |
| 46 | 老陆沉要完成七号钟 | 用正在碎裂的身体拉绳 | 苏照允许自己问一次未来私事 |
| 47 | 陆沉要验证眼前是不是女儿 | 木燕、错误尾羽、错误遗言 | 他打开院门，选择履行真实小满的差事 |
| 48 | 同一灵魂的两个陆沉要共同松手 | 红绳勒血、名字褪色、共同敲钟 | 小满记忆只离开两个陆沉，万名回城 |
| 49 | 裴九思要决定最后一次关门还是开门 | 裴安回声、飞出的记忆 | 他开门并留下活着认罪 |
| 50 | 老陆沉要在消失前交回空木鞘 | 两人已经不认识彼此 | 年轻陆沉伸手但不再抓住 |
| 51 | 苏照要把女儿重新介绍给已经遗忘她的父亲 | 她仍记得全部并短暂恨他；他的身体仍会托住后颈 | 陆沉第一次重新说出“女儿”并接过小满 |
| 52 | 陆沉要重新认识小满 | 读墓名、听米缸故事、请求“再讲一个” | 留下木燕，带着女儿交代的行动回城 |

## 五、重点试戏段落

- **陆沉 / 苏照**：第5场医馆。禁止吵成婚姻争执，要演成陆沉借查案请求回家、苏照拒绝让案件替代回答。
- **陆沉 / 老陆沉**：第28场学堂。两人都不是讲道理，而是在争夺“谁更有资格爱小满”。
- **苏照 / 小满**：第29、35、39场。关系依次从母亲救女儿、母女并肩、共同完成告别。
- **裴九思**：第19与30场连排。前一场校准假儿子，后一场招募真父亲，才能看见他把人当材料的同一习惯。
- **陆沉 / 剑中小满**：第47场。不要一开始就识破；陆沉应该真心享受她每个正确回答，直到“正确”本身变得可怕。
- **尾声双人**：第51场先无台词排练。只靠递孩子、托后颈、换抱姿完成，台词最后再加。
