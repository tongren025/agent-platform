## 三幕结构

- **第一幕「活着」EP01–03**：巷子打斗 → 假觉醒被掐灭 → 艾拉救场 → 龙蛋

- **第三幕「出发」EP08–10**：选择离开烬龙陆 → 骑龙升空 → 九大陆剪影

## 主要角色（视觉 DNA 见 `setting` / `design` 卡）

- **R3 苍霖**（主角）：16 岁少年，黑色短碎发凌乱，左脸颊竖向旧伤疤，偏瘦有韧劲，深褐近黑瞳孔，破烂灰褐麻布短衣，赤脚，胸口布条绑龙骨碎片。有三阶段演变（少年 / 中期 / 后期）。
- **R1 艾拉**：救场者。参考图见全局设计卡。
- **R2 巨龙**：龙骨碎片 → 龙蛋 → 巨龙，三阶段演变，AI 视觉奇观核心。
- **老矿工**（路人）：废土世界的质感锚点。

> 角色一致性铁律：每镜必须复述视觉 DNA + 引用角色母版图（`@图片1`），脸不变、服装不变、赤脚不变。

## 制作管线（10 阶段）

`创意/原著 → 剧本 → 角色·场景设定 → 视觉设计 → 分镜 → 图片提示词 → 视频提示词 → 生图 → 生视频 → 成片`

- **卡片组织**：`episode = null` 的卡是全局资产（跨集共享）；`episode = N` 的卡是该集镜头，按 `shot_number` 归组。
- **引擎**：Claude 代行数字员工团队（分镜师 → 提示词工程师 → 质检），团队 `comic-drama-team`。
- **风格底线**：干净半写实东方幻想漫剧插画，电影级特效关键帧；全程正向约束，禁负向提示词与"快速/fast"。
