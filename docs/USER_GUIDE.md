# Agent Studio 系统使用手册

> 适合第一次使用 Agent Studio 的创作者。系统内可从左侧 **获得帮助 → 系统使用手册**
> 打开图文版。普通页面可点击右下角问号重播新手引导；工作台入口位于对话标题栏。

## 1. 最短上手路径

第一次使用只需要记住四件事：

1. 打开左侧 **快速制作**，点击 **新建制作**。
2. 输入一句故事想法，例如：“失忆剑客发现追杀自己的人是未来的自己。”
3. 新手建议把交付目标设为 **制作完整成片**。
4. 页面会突出显示唯一的 **当前下一步**，完成后继续下一步即可。

已有作品不要重新创建：打开 **我的项目**，选择原项目继续制作。

## 2. 手机模式：灵感随手拍

手机登录后会自动打开 **灵感随手拍**。它和电脑共用项目、数字员工及模型配置，但只保留
适合随时创作的轻量流程：

1. **说灵感**：输入或语音说一句想法，也可以附一张参考图。
2. **找钩子**：选择反转悬念、情绪共鸣、视觉奇观或轻松搞笑。总导演每次只问一个问题，
   帮你补清楚前三秒、冲突和结尾。
3. **确认开拍**：选择 15 或 30 秒竖屏视频，点击 **按这个方向开拍**。
4. **逐步生成**：系统先完成文字阶段，再按镜头逐张生成画面、逐条生成视频。
5. **看过再继续**：满意才进入下一步；不满意只重做当前画面或视频。

手机页底部只有三个入口：

- **灵感**：继续和导演聊，或开始一个新想法；
- **制作**：查看唯一下一步和当前正在处理的 G 镜头；
- **作品**：打开已有手机小视频项目，继续上次进度。

手机使用的仍然是你在平台中配置的总导演、编剧、分镜、关键帧和视频员工，不会调用别的
系统的账号或模型。系统提供的是常见高互动叙事结构，不会冒充实时平台热榜。多集漫剧、
人物三视图、复杂场景资产和精细时间线，点击 **电脑精修** 后在电脑端继续。

## 3. 从创意到成片的完整流程

| 阶段 | 产出 | 说明 |
|---|---|---|
| 故事设定 | 世界观、背景、人物关系、剧情脉络 | 必需 |
| 剧本 | 场次、动作、台词、情绪、时长 | 必需 |
| 视觉母版 | 画风、色彩、光影、画幅、时代基调 | 必需 |
| 人物设定 | 正面、侧面、背面、表情、服装状态 | 主角必需 |
| 场景设定 | 场景全景、主要方向、日夜和灯光状态 | 高频场景必需 |
| 分镜图 | 每个镜头的构图、景别、人物位置 | 每镜必需 |
| 镜头动态 | 镜头时长、人物走位、运镜、剪辑节奏 | 每镜需要 |
| 首尾关键帧 | 视频开始与结束的干净画面 | 首帧强烈建议 |
| 视频生成 | 参考资产、关键帧和运动说明共同生成 | 逐镜执行 |
| 后期与交付 | 审核、镜头排序、成片合成与下载；字幕、声音、转场需另核对具体工具能力 | 后期要求不等于平台已全部实现，见 [功能大全](knowledge/FEATURES.md) 的边界说明 |

### 为什么人物三视图不能直接生视频

人物三视图是角色参考表，通常把正面、侧面和背面排在同一张图中。视频模型可能把它理解成
三个并排的人物。正确链路是：

```text
人物三视图 + 场景设定 + 分镜构图
→ 生成一张干净的镜头首帧
→ 首帧 + 可选尾帧 + 运动说明
→ 生成视频
```

## 4. 页面地图

### 灵感随手拍

手机轻制作入口。和总导演聊清一句灵感后，系统一次只展示一个下一步，并按镜头生成，
适合 15–30 秒竖屏小视频。

### 今日制作

展示最重要的项目、当前风险、运行任务和系统推荐下一步。普通用户通常从这里点击
**继续制作**。

### 快速制作

新手的主入口。系统将完整生产流程拆成一次只处理一个步骤的任务，并显示当前进度、
目标和下一步按钮。

### 我的项目

保存已有故事项目。可重新打开项目，继续上次未完成的集和镜头。

### 画布中心

用于逐镜生产。先选 **第几集**，再选 **镜头 G1、G2……**。画布只聚焦当前镜头和
必要的上游参考资产，避免整季一起渲染。

### 找数字员工帮忙

直接向编剧、导演、人物设计师、场景设计师、分镜师、视频师或质检员工提出问题。

### 管理数字员工

用于设置员工的文字、图片、视频模型和能力。新手通常不需要修改，先使用系统推荐配置。

### 系统管家

普通页面使用右下角耳机图标，工作台使用对话标题栏的耳机图标。管家能够识别当前页面、
检查模型和运行状态，适合处理“为什么没有回答”“哪个模型没配置”“刚才哪一步失败”等问题。

## 5. 逐镜画布操作

1. 在左侧制作目录选择一集。
2. 展开本集并选择镜头 G1、G2……
3. 顶部显示当前集、当前镜头、完成度和唯一下一步。
4. 点击 **创建当前镜头视频任务** 时，员工会根据当前镜头已有的剧本、人物、场景、
   分镜和关键帧补齐视频节点。
5. 当前镜头完成后切换到下一个镜头。
6. 重新生成或替换只影响当前镜头，不会改动整季。

画布中看不到整季所有节点是正常现象：这是逐镜聚焦模式，用来保证可读性和性能。

## 6. 模型与数字员工

- **数字员工**：理解需求、使用岗位提示词、规划步骤并调用工具。
- **文字模型**：负责剧本、提示词、导演规划和工具编排。
- **图片模型**：负责人物、场景、分镜和关键帧。
- **视频模型**：负责把首帧、尾帧和运动说明生成视频。

员工绑定的文字模型失效时，运行时会尝试平台中已启用且凭据完整的备用文字模型。
图片和视频模型不会被误当成文字模型使用。

模型速度受任务影响：

- 简单文字通常最快；
- 深度推理、长剧本和结构化工具调用更慢；
- 图片生成通常需要几十秒；
- 视频生成通常需要数分钟。

## 7. 提示词与学习

人物、场景、分镜、关键帧和视频分别使用专业生产提示词模板。画布输入框展示的是当前
项目要求，并不是系统提示词的全部内容。

- **提示词学习**：采集或录入高质量提示词范例。
- **文章学习**：学习导演、摄影、美术和叙事资料。
- **员工知识与记忆**：保存已验证的项目偏好和成功经验。

建议先做完一个短项目，再把满意结果作为范例。少量高质量范例通常优于大量未经筛选的
提示词。

## 8. 常见问题

### 模型一直很慢

先等待当前任务完成；图片和视频本来就比文字慢。如果长时间无结果，打开系统管家（工作台
在对话标题栏，其他页面在右下角），让它检查当前员工模型和最近运行。

### 员工不回答

确认员工有文字模型。生图员工还需要图片模型，视频员工还需要视频模型。系统会自动尝试
合适的备用文字模型，但无法替代尚未配置凭据的图片或视频服务。

### 画布很卡

确认正在使用逐镜聚焦模式，不要同时展开大量集。刷新后重新选择当前集和镜头；项目素材
失效时应替换为正式参考资产。

### 生成错了

切换到对应镜头，重新生成当前图片或视频。逐镜替换不会影响其他镜头。

### 不知道下一步

优先看快速制作页的 **当前下一步**。术语旁的小问号提供即时说明；普通页面右下角问号、
工作台对话标题栏问号均可打开快速帮助和重播新手引导。

## 9. 推荐的新手工作方式

- 第一个项目控制在 30–60 秒；
- 主角先完成三视图、常用表情和标准服装；
- 高频场景先做统一设定图；
- 每次只推进一个镜头；
- 视频生成前认真检查首帧；
- 每完成一集就审片，不要等整季生成后才检查一致性。
