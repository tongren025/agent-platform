# 漫剧提示词标准 v3（分镜 / 首帧图 / 视频）

本文档是《九陆纪元》卡池三类模型侧资产的**唯一现行标准**，由
`scripts/prompt_pipeline_v3.py` 强制执行。历史背景：v2 及更早的卡片由模板脚本
机械拼接生成，存在四类致命问题，v3 逐条修复：

| # | 旧问题 | v3 修复 |
|---|--------|---------|
| 1 | 视频提示词把 10~18s、9 个镜头塞进一次生成（"零丢弃"），模型在长时序里角色变形、切镜糊掉 | 每个 G 拆成 **4~6s 生成子段**（子段=一次生成调用），子段间用"末帧截图接力"衔接，成本不变（按秒计费），返工粒度从整 G 降到单子段 |
| 2 | 画质后缀全是负向词（无墨线/无裂纹/避免抖动…），Seedance 2.0 不读负向词，反而被"墨线/裂纹/抖动"这些名词引导出伪影 | 后缀只写**想要的结果**（正向约束），负向词零容忍，由静态门禁拦截 |
| 3 | 镜头行是电报式碎片（"光丝②尽头:碎星环环绕浮空城·魔法阵光纹…"），模型解析不了空间关系和动作主体 | 每镜写成 **1~3 句流畅中文**：空间布局 → 主体（具体名词+2~3 静态特征）→ 身体部位级动作，禁止 "·/|/:" 拼接 |
| 4 | 分镜卡的主体、起止姿态、前中后景由规则代码猜测生成，出现"主体与焦点：上百道"式的错误和整段通用填充句 | 每镜的主体/姿态/分层由 LLM 按剧本逐镜思考产出，管线校验具体性（黑名单模板句直接判废） |

---

## 一、G 与子段的关系（生成经济学）

- **G**：看板组织单元（10~18s 成片），对应 1 张首帧图 + 1 张视频卡 + 1 张分镜卡。
- **子段（Sub-segment）**：真正送入视频模型的一次连续生成，**4~6s**（下限 3s 需标注补齐损耗）。
- 划分算法：按剧本剪辑段（1~3s/段）连续分箱，目标 4~6s，箱数 = ceil(总时长/6)，尽量均匀。
- 衔接：子段 A 用 G 首帧图起手；子段 B 用「子段 A 末帧截图」作首帧；末段如有 FLF 末帧锁则同时锁尾。
- 成本：按生成秒数计费，3 条 4~6s ≈ 1 条 14s，但**质量和返工成本完全不同**。

硬规则（违反任一条渲染即失败）：
1. 每个子段是**独立完整提示词**，可直接整段复制进即梦/Seedance；角色 DNA 在每个子段完整重复。
2. 每「镜头」只允许**一个**运镜动作，中英双写（如 缓慢推进(dolly in)）；镜头运动和角色动作分开成句。
3. 只写正向内容。全文禁止：不要/避免/禁止/无墨线/无裂纹/无噪点/no/without；禁止 快速/高速/飞速/剧烈/激烈/fast。
4. 纯中文（运镜术语双写除外）；台词逐字保留剧本原文。
5. 战斗/高特效镜头用战斗风格锚（追加"电影级高特效动作关键帧，蓝白魔法阵与赤金龙焰对撞"）；普通叙事镜头用干净常规锚，不加战斗特效词。
6. 文件头 `file:`、尾部 `Motion:`/`Script:` 行是下游自动化契约，逐字保留。

## 三、img_prompt v2 卡片格式（七要素，保留编号结构）

- ①风格：常规锚或战斗锚（同上判定）。
- ②主体：R 编号 + 当集时期版本完整 DNA（沿用本集卡池已锁定的 DNA 字符串，禁止改写或降级到旧时期）。
- ③动作：**首帧定格瞬间**的身体部位级姿态（不是本 G 剧情摘要）。
- ④景别构图：景别/机位 + 竖屏9:16 + 主体画面位置 + 前中后景各有什么，写成流畅句子。
- ⑤光影：一个主光 + 一个辅光，写方向与色温。
- ⑥情绪氛围：用可见元素表达（体积光/余烬/雨丝…），不写音效、不写 "+3" 情绪评分。
- ⑦画质：正向约束——"主体边缘清晰，面部结构完整立体，五官清楚，人体比例自然，画面稳定干净，背景层次分明，色彩通透，竖屏9:16，电影质感"。
- 末帧锁（FLF）卡同结构，③写末帧定格瞬间。

## 四、storyboard v2.1 卡片格式（每 G 一张）

头部：G 名 | 成片时长 | 子段划分（与 vid 卡一致）| 首帧/成片文件 | 连续性基准。
每镜必含（门禁字段）：镜头目的 / 景别·机位 / 唯一运镜 / 主体与焦点 / 画面位置 /
前景·中景·背景 / 视线方向与轴线 / 起始姿态 / 分时动作（2~4 拍）/ 结束姿态 /
光影 / 声音 / 剪辑与承接 / 所属子段。
全部字段必须是**该镜头专属的具体内容**。以下模板句出现即判废：
"变化从一个明确起点开始"“用场景最近地标建立尺度”“延续上一镜永久地标”
"处于变化前基准状态"“先改变一个最关键的可见部位”。

## 五、逐镜写作方法（给改写者）

1. 先读剧本行的【动作】列，问自己：**画面里到底能看见什么？** 把抽象概念翻译成
   可见名词（"资格存疑" → "棱镜表面的白色光纹卡在半格，忽明忽暗"）。
2. 主体 = 画面中真正发生变化的那个东西；角色在场但不动时，主体可以是道具/光/环境。
3. 动作按身体部位链写：重心 → 躯干 → 肢体 → 末端；优先慢速连续小动作。
4. 空间三层各司其职：前景给尺度、中景给事件、背景给氛围；背景永远比主体简单。
5. 情绪列（如"欠揍 +2"）不进提示词，翻译成可见的表情肌肉/姿态/光线。
6. 台词镜头：先写口型启动（吸气、下唇先动），台词原文放音频层。
7. 每镜结束姿态必须能被下一镜起始姿态接住（轴线、朝向、道具手不跳变）。
