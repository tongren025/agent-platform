真人山海经：100个独立首集剧本
日期：2026-10-27

范围
100个不同首集候选，10种大类，每类10篇。均以120秒作为剪辑目标，前110秒为真人戏，末10秒揭示巨兽；未做动态分镜试剪，实际台词与动作仍需排练校时。
取消偶像、职业打卡、开工收工、穿越、修仙与升级设定。山海世界直接存在；剧情使用活的人物关系、悬念、怪诞规则与感官场面。
演员按成年角色选型；高颜值使用自然骨相、皮肤、衣料与有辨识度的配色，避免整齐塑料脸。

怎么挑
先打开“真人山海经_100个首集剧本.xlsx”的“100篇目录”，按类型筛选，黄色“选择”栏可选优先、保留、待改、放弃。定位栏给出正文工作表和起始行。每类工作表内依次放10篇完整正文。
逐篇纯文本在scripts/，全本在全部100篇.txt，结构化源数据在scripts.json。编号是固定标识，反馈直接报编号即可。

改编边界
原著识别特征见目录下方依据。人形、巨大化、关系、情节与本篇出现的特殊术法为影视原创；不同篇独立试设定。
各篇只标注创作方向，不预测播放量，也不将网络热梗拼贴当作原创剧情。旧版10篇中的穿越设定不沿用。
