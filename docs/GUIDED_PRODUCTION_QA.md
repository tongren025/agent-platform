# 10 步漫剧制作向导测试用例

本文覆盖 Agent Studio 画布中“只按下一步即可完成”的主路径。自动化验收一律使用隔离项目和测试替身；除非人工明确确认，不调用真实图片、视频生成服务，不消耗生产额度。

## 通过标准

- 每个阶段只显示一个明确主按钮；单击一次必须有可见响应，并且只触发当前阶段动作。
- 首次进入目标工作区时也不能丢动作，用户不需要重复点击、手动展开助手或选择节点。
- 规划动作不扣费；付费生成只在用户点击“确认额度并生成”后启动。
- 连续点击、刷新、失败重试不能重复授权、重复建卡或重复入轨。
- 阶段进度只由真实文稿、有效节点、生成结果和实际入轨视频推导，空占位和无关素材不能让阶段误完成。

## 主路径用例

| 编号 | 阶段 | 操作 | 预期结果 |
|---|---|---|---|
| GP-01 | 登录与项目库 | 登录后进入 `/canvas` | 显示项目库；无阻断性错误；画布自己的引导不与平台全局引导重叠 |
| GP-02 | 新建项目 | 单击“新建空白项目” | 只创建一个项目并进入第 1/10 步，默认落在创作区 |
| GP-03 | 第 1 步：创意 | 单击“去写一句话” | 创作原稿编辑器获得焦点，可立即输入，不需要再寻找输入框 |
| GP-04 | 第 1 步：创意 | 输入少于 4 个字符 | 仍停留第 1 步，不误判完成 |
| GP-05 | 第 1 步：创意 | 输入有效故事创意 | 自动进入第 2/10 步，文稿自动保存 |
| GP-06 | 第 2 步：剧本 | 单击“生成剧本” | 只派发一次编剧任务，要求 `append_to_end`，结果写回原稿并进入第 3 步 |
| GP-07 | 第 3 步：风格规划 | 单击“建立风格母版” | 一次点击即唤醒生成助手并创建文字母版和风格图节点；不扣费 |
| GP-08 | 第 3 步：风格生成 | 单击“确认额度并生成母版图” | 只授权并生成本阶段待生成节点；成功后进入第 4 步 |
| GP-09 | 第 4 步：角色规划 | 单击角色主按钮 | 按主要角色建立人物参考卡，不重复同名角色；不扣费 |
| GP-10 | 第 4 步：角色生成 | 单击额度确认按钮 | 只生成人物阶段节点；所有主要角色成功后进入第 5 步 |
| GP-11 | 第 5 步：场景规划 | 单击场景主按钮 | 按剧本地点建立场景/关键道具卡；不创建分镜；不扣费 |
| GP-12 | 第 5 步：场景生成 | 单击额度确认按钮 | 只生成场景阶段节点；全部成功后进入第 6 步 |
| GP-13 | 第 6 步：分镜规划 | 单击“把剧本拆成逐镜分镜图” | 生成结构化分镜方案，不直接创建重复镜头，不扣费 |
| GP-14 | 第 6 步：方案审核 | 方案未提交时单击顶部按钮 | 打开分镜方案编辑器，不重新规划、不启动生成 |
| GP-15 | 第 6 步：分镜生成 | 提交方案后单击额度确认按钮 | 只生成有效、非空提示词的分镜节点；成功后进入第 7 步 |
| GP-16 | 第 7 步：镜头动态 | 单击动态设计主按钮 | 每个分镜都有且只有一张动态设计卡；固定镜头也有静止机位说明；不扣费 |
| GP-17 | 第 8 步：关键帧规划 | 单击关键帧主按钮 | 每镜建立首帧，必要时建立尾帧，并正确连接风格/角色/场景/分镜参考；不扣费 |
| GP-18 | 第 8 步：关键帧生成 | 单击额度确认按钮 | 只生成关键帧阶段节点；每个分镜至少有一个成功关键帧才进入第 9 步 |
| GP-19 | 第 9 步：视频规划 | 单击视频主按钮 | 每镜建立独立视频节点并连接首尾帧；不把多镜塞进一个节点；不扣费 |
| GP-20 | 第 9 步：视频生成 | 单击额度确认按钮 | 只生成视频阶段节点；所有镜头视频成功后进入第 10 步 |
| GP-21 | 第 10 步：审片 | 单击审片主按钮 | 成功视频按镜号依次、去重加入时间轴，并切换预览区 |
| GP-22 | 全部完成 | 所有镜头视频均已入轨 | 显示 10/10 完成；重复点击不重复加入时间轴 |

## 状态、失败与防重复用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| GP-23 | 首次加载助手 | 从创作区直接点击任一画布规划按钮 | 助手先挂载再消费请求；第一次点击不丢失 |
| GP-24 | 连续点击 | 快速双击任一额度生成按钮 | 只铸造一次授权、只执行一份计划；按钮显示启动中/生成中并禁用 |
| GP-25 | 生成中 | 节点为 queued/running 时再点顶部按钮 | 不重复下单，不创建重复节点 |
| GP-26 | 授权失败 | 让额度授权返回错误后再次点击 | 错误为可理解中文，锁被释放，下一次可重试 |
| GP-27 | 空提示词 | 分镜/关键帧/视频节点 prompt 为空 | 授权前拦截，不扣费，不显示无效“重试”，不计入已规划 |
| GP-28 | 部分失败 | 同阶段一个节点成功、一个节点失败 | 停留当前阶段；重试只选择失败/待生成节点，不重跑成功节点 |
| GP-29 | AI 只回文字 | 规划任务未返回要求的工具调用 | 明确提示任务未执行，不伪装成功，不推进阶段 |
| GP-30 | 工作区切换 | 动作派发同时从创作切到生成或从生成切到创作 | 待处理请求被目标面板消费，不因懒加载丢失 |
| GP-31 | 刷新续接 | 在每个阶段刷新页面 | 项目、文稿、节点、方案、时间轴与当前阶段恢复一致 |
| GP-32 | 返回再进入 | 回项目库后重新打开测试项目 | 从真实未完成阶段继续，不回到第 1 步，不丢对话/素材 |
| GP-33 | 旧节点兼容 | 已有媒体结果但 prompt 丢失 | 旧结果仍计为完成，但不会再次进入待生成队列 |
| GP-34 | 阶段隔离 | 同时存在角色、场景、分镜待生成节点 | 顶部按钮只选择当前阶段节点，不串阶段扣费 |
| GP-35 | 审片覆盖 | 时间轴只有文本、音频或重复同一视频片段 | 不得判定 10/10；每个分镜对应的成功视频实际入轨后才完成 |
| GP-36 | 项目隔离 | 两个项目来回打开并执行按钮 | 请求、确认卡、节点、对话和长期状态不能串到另一个项目 |
| GP-37 | 视口与遮挡 | 1920×1080、1366×768 下点击顶部主按钮 | 按钮可见可点；全局帮助、上手清单、助手和弹层不遮挡主路径 |
| GP-38 | API/资源异常 | 模拟 401、404、429、500 和断网 | 页面不白屏；错误可关闭、可重试；401 回登录，其余不清除有效登录态 |

## 自动化分层

- 纯逻辑测试：阶段推导、当前阶段节点选择、空提示词拦截、依赖波次、审片入轨覆盖。
- 按钮控制器测试：10 个阶段逐一点击、动作唯一性、同步防双击锁、授权失败解锁。
- 浏览器测试：登录、新建隔离项目、真实按钮点击、跨工作区懒加载、刷新续接、弹层遮挡和错误呈现。
- 构建门禁：TypeScript、Vitest、Web/Agent Canvas 生产构建以及变更文件静态检查。
