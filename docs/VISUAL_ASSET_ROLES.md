# 视觉资产用途规矩（2026-07-21 定稿）

> 背景：S1 分镜图三轮全量重制（四格分镜 → 五格轨迹板 → 石墨线稿制片板），每轮换形态仍不满意。
> 根因不是画得不好，而是**一张图在同时伺候三个用途**——审节奏、垫生图构图、当视频首末帧——
> 三个用途对"好"的定义互斥，用途不定，怎么画都能挑出毛病。本文件定死每类资产的唯一用途
> 与唯一验收问题。**S1 不再做第四轮全量重制**；后续只按此标准逐 G 补齐，先 EP01。

## 三类视觉资产，各答一个问题

| 资产 | 唯一用途 | 唯一验收问题 | 谁看 |
|------|---------|-------------|------|
| **制片故事板**（storyboard 卡图） | 审剧情节拍 | 这个画面是不是这一镜的决定性节拍？ | 人 |
| **首帧图**（img_prompt 卡图） | 视频生成起点 | 这一帧能不能直接当视频第 0 秒？ | 视频模型 |
| **轨迹板**（action_trajectory 资产） | 运动描述参考 | 视频提示词里的运镜/动作能否照它写出来？ | 写 vid_prompt 时 |

一张图**只**回答自己那个问题。审故事板时挑"细节不够精致"、审首帧时挑"节拍感不强"，都是拿错验收标准——发现自己在跨类挑毛病时停下。

## 首帧图的三重锁（缺一不给过）

1. **角色锁**：@图片1 = 角色母版（R 编号对应时期版本）；
2. **基调锁**：@图片2 = 对应分型的基调板（`g-tone-01..05`，见 jiulu-s1 design 阶段）——
   基调用参考图物理锁定，提示词里的"配色权重"句只是辅助；
3. **配色权重句**：④里必须有显式主次比例与次色出现范围（"冷暖不均分，单一主光源定基调"）。

## 评审纪律

- 图片验收走单集详情页的**通过/废弃两键**；废弃必选原因（基调偏差/角色走形/构图不符分镜/光影错误/结构崩坏/其他）。
- 统计条显示废弃原因分布——**哪个原因占大头，就先集中修哪个**；禁止"不满意→整批重做"。
- 卡片 `status=done` 只表示"生成完成"，验收结论以 `metadata.review_verdict` 为准。

## 风格句纪律（防再污染）

全局风格锚点句只写**风格**（画风/质感/光的性格），永不写具体画面元素。
"蓝白魔法阵与赤金龙焰对撞"类的画面内容只允许出现在单卡自己的③④里。
