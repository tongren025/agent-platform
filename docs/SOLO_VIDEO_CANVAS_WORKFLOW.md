# 一人团队：自由画布稳定出片手册

这份手册只服务一个目标：**一个人能持续把想法推进为可交付视频，并且每一步都能自己接管。**

自由画布不是“自动保证好片”的按钮，也不是另一套复杂流程。它是一张人工主控桌：文本、参考图、生成图、镜头视频和成片都放在同一个空间里；AI 只在你主动点击时工作。

## 1. 最短出片路径

1. 新建一张画布，一集或一个短片一张，不要把整季全部塞进同一张。
2. 建文本节点，写清这一镜的目的、画面、动作、时长和声音；手动选择“剧本 / 分镜 / 图片提示词 / 视频提示词”等阶段。
3. 选择以下任一方式得到画面：
   - 画布直接“出图”；
   - 复制提示词到外部工具生成，再把图片拖回画布；
   - 直接上传已有参考图。
4. 图片先标记“待审核”。确认人物、服装、场景和构图后，手动改为“已通过”。
5. 从文本节点做文生视频，或从图片节点做首帧图生视频；也可以把外部生成的视频直接拖回画布。
6. 逐条播放视频，只有真正可用的镜头才标记“已通过”。
7. 把通过的镜头按从左到右、同列从上到下排好，点击“合成已通过镜头”。
8. 播放成片节点，完成最后审核后下载；需要精细字幕、调色、转场和混音时，再进入专业剪辑软件收尾。

## 2. 三种工作方式可以混用

| 工作方式 | 怎么做 | 适合什么情况 |
|---|---|---|
| 完全手工 | 写节点、上传图片/视频、人工连线 | 已有素材或想完全掌控 |
| 半自动 | 画布整理提示词，复制到小云雀/即梦等外部工具，结果拖回 | 外部生成质量更好或成本更合适 |
| 平台生成 | 节点直接出图/出视频，完成后刷新任务 | 已配置可用模型，希望少搬运 |

三种方式产生的节点拥有同样的审核状态和合成资格，不会强迫你走某个供应商或某条固定流水线。

## 3. 保证质量靠四次人工拍板

### 剧本通过

- 单镜只表达一个主要动作或信息。
- 台词与画面能在目标时长内完成。
- 人物动机和前后镜头连续。

### 图片通过

- 人物脸、发型、服装、道具与参考设定一致。
- 构图适合目标画幅，主体没有被 UI/字幕安全区截断。
- 手指、文字、水印、肢体和透视没有明显错误。

### 视频通过

- 首帧身份没有漂移，运动方向符合分镜。
- 没有突然变脸、闪烁、穿帮或不需要的镜头运动。
- 有效时长足够，开头和结尾能与相邻镜头衔接。

### 成片通过

- 镜头顺序正确，没有漏镜、重复镜头或黑帧。
- 节奏、对白、音乐和字幕能够完整观看。
- 在手机竖屏或目标终端上完整播放一次。

画布只会合成标记为“已通过”的视频，避免草稿和待审结果误入成片。

## 4. 防止返工的使用习惯

- 一张画布只承载一个明确交付物。
- 节点标题使用 `G01-S01 动作` 这类可排序名称。
- 连线表示“由谁产生”，位置表示最终播放顺序；不要混用。
- AI 生成结果默认是“待审核”，不要为了看起来进度快而批量通过。
- 每次大改前点“导出备份”；JSON 可重新导入当前画布。
- 看到“保存失败”立即手动保存，不要关闭页面；多窗口版本冲突会返回错误而不是静默覆盖。

## 5. 当前能力边界

- 平台视频生成目前依赖已启用的 OpenRouter 视频模型；没有配置时仍可上传外部生成结果完成全流程。
- 平台合成使用本机 FFmpeg，当前是按顺序统一画幅并串接镜头，不代替专业剪辑软件的字幕、复杂转场、调色和精细混音。
- 画布能保证数据保存、审核门禁和镜头顺序，但不能保证生成模型每次都产出高审美结果；最终质量仍由“参考设定 + 提示词 + 人工审核 + 返工”共同决定。

## 6. 一人团队每次只看四个数字

- 一次通过率：生成后不返工即可使用的镜头比例。
- 单镜返工次数：超过 3 次时应改提示词或换模型，而不是盲抽。
- 已通过镜头覆盖率：计划镜头中完成审核的比例。
- 成片人工修复时间：系统是否真的减少了剪辑和搬运时间。

如果连续三条片子的人工修复时间没有下降，就应删掉没有帮助的自动步骤，而不是继续增加系统功能。
