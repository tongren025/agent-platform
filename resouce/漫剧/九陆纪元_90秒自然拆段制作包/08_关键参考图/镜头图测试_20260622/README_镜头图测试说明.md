# 镜头图测试说明 2026-06-22

本组不是宫格故事板，也不是动态漫图。用途是测试“高精度国风奇幻半写实厚涂快节奏漫剧风”的单镜头关键参考图效果。

## 图片清单

- `S01_竞技场巨龙压场_艾拉起势.png`
  - 用途：开场建立空间，测试巨龙压场、竞技场废墟、艾拉起势。
  - 初判：大场面清楚，龙和竞技场有压迫感；艾拉是背面，适合作场景/气势参考，不适合作角色脸部锁定。

- `S02_艾拉闪避龙爪_星环防御.png`
  - 用途：测试艾拉主体清晰、脸手可读、魔法阵防御、龙爪打击点。
  - 初判：目前最接近可用镜头图，主体占比、魔法阵和动作关系都比较清楚。

- `S03_艾拉踏星盾反击龙翼.png`
  - 用途：测试龙改变攻击方式、艾拉踩星盾反击龙翼，表现来回攻防。
  - 初判：动作感强，能读出反击；风线和粒子略多，后续可再压低特效密度。

- `S04_苍霖苹果反转入场.png`
  - 用途：测试男主帅度、露胸龙族废墟风格、苹果反转、巨龙反应。
  - 初判：男主方向更对，能读出懒散危险和反转钩子；整体偏暗，龙鳞细节略密，后续可提升脸部亮度和减少背景高频纹理。

## 下一版提示词修正方向

- 保留：清晰主体、干净边缘、半写实厚涂、快节奏漫剧镜头感。
- 加强：脸部主光、手部清晰、角色主体占比、动作因果。
- 压低：龙鳞高频纹理、飞散火星、风线、远景废墟碎细节。
- 禁止：动态漫、漫画动效、宫格分镜、黑线边框、随机黑线、文字、水印。
