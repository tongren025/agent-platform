## 根因分析：提示词哪里出了问题

### 问题 1：风格锚点句缺失或被覆盖

**现象**：生成图的风格在"暗黑写实"（雨巷、暴徒）和"华丽抽卡"（艾拉、苍霖性感版）之间随机摇摆。

**根因**：早期提示词**没有固定的风格锚点句**。Art Bible 规定每条提示词开头必须带：
```
干净半写实东方幻想漫剧插画，电影级高特效动作关键帧，柔和漫射光，清晰主体，低描边
```
但实际生成时这句话根本不存在，或者被具体画面描述挤掉了。模型在没有风格锚定的情况下，
默认走向了它训练集里最常见的两种"高质量"方向：暗黑写实 或 日系抽卡。

**修复**：STAGE_INSTRUCTIONS 里已注入风格锚点句（上一轮做的），重生成时必须检查锚点句在提示词第一行。

### 问题 2：角色视觉 DNA 不完整或不一致

**现象**：
- 艾拉正式母版 = 白发短发科幻制服（应该是黑长发银蓝高光+星环法师战斗装）
- 苍霖各版本在 "弱小少年" 和 "肌肉猛男" 之间反复横跳
- 巨龙在 "青蓝龙" 和 "红火龙" 之间完全不同

**根因**：提示词里**没有带完整的角色视觉 DNA 描述**。每次生成只是写了一个笼统的角色名，
让模型自由发挥。Art Bible 要求每条出现角色的提示词都必须**完整重复** DNA 描述
（发型+瞳色+伤疤+服装+道具），不能"依赖上下文"。

**加重因素**：不同时期的角色版本混淆。苍霖 EP01-03 是"赤脚破布"，EP04-08 加毯子披风，
EP09-10 换龙鳞披风。提示词没有指定当前集对应的版本。

### 问题 3：正向约束词和禁止清单缺失

**现象**：
- 大量死黑阴影（Art Bible 明确禁止）
- 墨线/描边风格（Art Bible 明确禁止）
- 裂纹划痕纹理（Art Bible 明确禁止）
- 宫格分镜格式（Art Bible 明确禁止）

**根因**：提示词结尾没有带正向约束词：
```
画面干净无描边，无墨线，无裂纹，无草稿线，无脏黑边，无死黑阴影，无文字水印，
保持角色一致性，服装不漂移...
```
也没有检查禁止清单。模型在缺乏约束时默认走向了"有视觉冲击力"的方向——
结果就是死黑阴影、裂纹质感、粗描边等 Art Bible 明令禁止的元素。

### 问题 4：配色权重未指定

**现象**：每张图配色随机，雨巷几乎全黑，竞技场红橙为主，艾拉设定图紫蓝为主。

**根因**：Art Bible 规定每张图必须带配色权重句式：
```
配色权重：暖赤金80%主导，冷蓝≤20%仅限净化光束，金绿限世界树光丝
```
但提示词里完全没有配色指令。模型根据"感觉"分配颜色，导致：
- 该暖的场景（高燃/爽）变冷暗
- 该冷的场景（压迫/危）变过暗到死黑
- 紫色、粉色等完全不在 Art Bible 色域里的颜色出现

### 问题 5：宫格分镜不是正确的输出格式

**现象**：所有分镜故事板都是 12格/24格/48格 宫格排列。

**根因**：Seedance 生成视频用的是**单张图片+运镜指令**，不是宫格分镜。
Art Bible 明确禁止宫格分镜格式。分镜应该是每镜一张独立图，
不是多格拼在一起的漫画页。这属于工作流理解错误——
把"电影分镜"做成了"漫画宫格"。

### 问题 6：暴徒/配角设计过度黑暗化

**现象**：暴徒三人组看起来像恶魔/怪物，不是人类混混。

**根因**：提示词可能只写了"暴徒"/"追杀者"等关键词，没有约束他们是**人类**。
模型把"暴力追杀者"理解成了暗黑幻想里的恶魔。应该在提示词里明确：
"废墟区的人类混混，破旧平民衣物，面容凶悍但是人类"。

## 核心教训

> **提示词不是"描述你想看到什么"，是"描述整个美学体系然后在里面放一个镜头"。**
>
> 缺风格锚点 → 基调漂移。缺角色 DNA → 角色走样。缺正向约束 → 禁止元素涌入。缺配色权重 → 颜色失控。
> 这四根柱子少任何一根，出来的图就是垃圾。
