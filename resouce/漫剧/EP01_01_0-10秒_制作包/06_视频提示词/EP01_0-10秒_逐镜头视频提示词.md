# EP01 0-10秒逐镜头视频提示词

## 通用角色固定

艾拉：成年年轻东方幻想女法师，长黑发带银蓝高光，清冷精致五官，少女感强但明确成年，性感但不低俗。黑蓝露肩星环法师战斗装，精致战斗短裤/短裙式战斗裙，透明纱质外摆，大腿绑带，膝上长靴，手持细长暗金属法杖。蓝白星环、透明几何法阵、晶体粒子。

巨龙：巨大远古龙，半透明翼膜与清晰血管纹理，锋利角冠，长吻，层层颈鳞，熔金龙瞳，胸腔和喉部白热龙焰，暗红黑金鳞片，翼展遮天。

场景：黄昏竞技场废墟，断裂石柱、塌陷看台、碎石、尘埃、赤金火星，橘红天空与深蓝云层。

通用画质：干净半写实东方幻想漫剧插画，精修 keyframe，电影级动作画面，柔和漫射光，清晰锐利边缘，干净色彩过渡，低描边，平衡对比度，主体清晰。

通用负面：粗黑描边，重墨线，黑色裂纹，随机黑线，草稿线，漫画排线，脏黑边，刮痕纹理，死黑阴影，黑色噪点，脏污线稿，噪点，颗粒，浑浊色彩，油腻高光，塑料质感，动作僵硬，逻辑混乱，人物漂移，服装漂移，龙结构不清。

## 镜头 01 / 0-1.2s / 巨龙压场

视频提示词：广角低角度固定镜头，从竞技场碎石前景缓慢上仰。巨大远古龙从黄昏云层中压下来，双翼遮住天空，半透明翼膜血管清晰，熔金龙瞳俯视地面，尾巴扫过远处断柱，赤金火星和尘埃被风压卷向镜头。动作流畅，龙翼风压强烈，史诗压迫感。

同期声：龙翼低沉风压，断柱崩裂，碎石滚动。

## 镜头 02 / 1.2-2.4s / 艾拉起阵

视频提示词：镜头从中远景推近，绕断柱右侧半圈。艾拉站在断柱顶端，长黑发和透明纱质外摆被风吹起，右手抬起，三层蓝白星环魔法阵在掌心前展开，晶体粒子绕手腕旋转，左手法杖点住断柱边缘。她眼神冷静，表情专注。

同期声：蓝白法阵低频嗡鸣，晶体粒子轻响，风吹布料。

## 镜头 03 / 2.4-3.4s / 龙焰蓄力

视频提示词：龙头特写切艾拉侧脸特写。巨龙喉部白热光逐层亮起，颈鳞缝隙透出赤金裂光；艾拉瞳孔倒映龙焰与蓝色星环，法杖横过身前，蓝色光环压缩成盾形。红金龙焰与青蓝魔法光效对撞，气氛紧绷。

同期声：高温气流，鳞片摩擦，法阵转速升高。

## 镜头 04 / 3.4-4.8s / 龙焰横扫，艾拉跃起

视频提示词：广角动作镜头跟随艾拉从断柱跃出。龙焰横扫断柱，石柱炸裂，艾拉从火光边缘跃出，脚尖点碎石借力，身体在空中拧转，三枚蓝白星环高速旋转拖出干净弧形光带，透明纱质外摆像星云展开。动作流畅无卡顿。

同期声：火焰轰鸣，石柱爆裂，星环切风。

## 镜头 05 / 4.8-6.2s / 星环反击

视频提示词：镜头跟随蓝色螺旋法阵射线飞向巨龙。艾拉在半空展开大型透明几何星阵，阵心射出蓝白螺旋光束，精准击中巨龙左翼翼根，龙翼表面溅起赤金火星和蓝色晶体粒子，巨龙身体短暂失衡并怒吼。

同期声：法阵轰鸣，能量击中鳞片的震音，龙怒吼。

## 镜头 06 / 6.2-7.4s / 护盾承压

视频提示词：低角度跟拍，巨龙巨爪从画面上方压下砸向艾拉落点，地面裂开。艾拉单膝滑跪，左手撑开半透明蓝色六边形护盾，右手法杖反插地面稳住重心，靴底在石面擦出火星，碎石被护盾挡开。冲击感强。

同期声：巨爪砸地重低音，护盾震颤，碎石滚落。

## 镜头 07 / 7.4-8.7s / 法阵反包围

视频提示词：鸟瞰转环绕，围绕艾拉和巨龙旋转半圈。竞技场地面、断柱侧面、空中碎石上同时亮起多个蓝白圆阵，像星图坐标一样围住巨龙。艾拉站起，法杖向上挑，七个小型星环同时升空，绕巨龙脖颈和翼骨旋转。巨龙甩头挣脱。

同期声：多层法阵叠加嗡鸣，龙翼拍打风压。

## 镜头 08 / 8.7-10s / 龙翼破阵

视频提示词：快速推近巨龙，随后甩回艾拉正面。巨龙张开双翼，赤金光从翼膜血管纹路中亮起，一次震翼震碎外层星环，蓝色碎光像玻璃一样散落。艾拉被冲击逼退，左脚踩到断裂石板边缘，身体后仰但稳住，反手收杖准备下一轮法术，眼神被激起胜负欲。

同期声：星环破碎，巨龙咆哮，风压爆音。
