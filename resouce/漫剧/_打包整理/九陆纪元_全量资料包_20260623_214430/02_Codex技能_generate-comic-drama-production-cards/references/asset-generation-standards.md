# 角色图、场景图、分镜图和关键参考图规范

## 通用干净画面规范

正向词：

干净的插图、平滑自然的阴影、柔和的漫射光、可控的细节、简约而精致的纹理、高清晰度、清晰锐利的边缘、干净的色彩过渡、平滑的渐变、平衡的对比度、精细的画面、清晰的主题、视觉上干净的构图。

公共美术画风锁定：

精致二次元国风奇幻厚涂设定稿、商业快节奏漫剧关键帧质感、大主体、清晰脸部、清晰手部、清晰服装结构、干净边缘、低噪点、低干扰背景、粒子可控、背景细节成组而不是满屏碎纹。

负向词：

噪点、颗粒、瑕疵、脏污的纹理、浑浊的色彩、过度锐化、斑驳的阴影、混乱的细节、过多的高频噪点、强烈的对比度、油腻的高光、塑料质感、粗黑描边、重墨线、黑色裂纹、随机黑线、草稿线、漫画排线、脏黑边、刮痕纹理、死黑阴影、脏污线稿、水印、logo、文字乱码、人物变形、脸部崩坏、手指错误、多余肢体。

## 角色图规范

角色图只负责稳定角色，不负责复杂剧情动作。

必须写：

- 角色姓名和身份
- 年龄感和气质
- 脸型、五官、眼神
- 发型、发色、发丝质感
- 身材比例、肌肉或柔软程度
- 服装结构、材质、暴露区域、配色
- 标志道具和能力特效
- 站姿或简单动作
- 表情版本：冷淡、受伤、愤怒、警觉、微笑等
- 禁止漂移项

清晰度硬性要求：

- 主体占画面 45%-70%。
- 脸、眼睛、手、发型、伤痕、服装结构必须清楚。
- 不要运动模糊、景深糊脸、烟尘遮脸、过多粒子、复杂战场背景。
- 如果需要性感、战损、弱小、狂暴等气质，优先通过体态、露肤区域、伤痕、服装剪裁和眼神表达，不靠脏纹理堆质感。

角色图类型：

- 单人正面设定图
- 三视图
- 表情图
- 服装变体
- 战损状态图
- 特效能力展示图

## 场景图规范

场景图只负责稳定空间，不负责完整剧情。

必须写：

- 场景名称
- 场景时代和文明风格
- 室内/室外/废墟/战场/洞穴/城市等类型
- 空间结构：前景、中景、远景
- 角色可移动路线
- 光源位置和光线性质
- 天气和空气状态
- 关键物件
- 材质：石头、金属、玻璃、骨骼、泥水等
- 色彩基调
- 镜头视角
- 禁止漂移项

清晰度硬性要求：

- 优先空镜，或人物只作为比例尺。
- 场景可以宏大，但细节必须成组，不能用满屏碎石、火星、裂纹和魔法点制造伪精细。
- 必须看清角色可移动路线、障碍物、高低差和光源方向。
- 场景图不是连续战斗图，不要在同一张图里塞多段动作。

打斗场景额外写：

- 障碍物
- 掩体
- 高低差
- 可破坏物
- 角色起点和终点
- 攻击路线

## 分镜图规范

分镜图负责单个镜头的高光帧或首帧。

必须写：

- 镜头 ID
- 所属视频段
- 出场角色
- 场景
- 景别
- 构图
- 角度
- 角色动作
- 表情
- 特效位置
- 运动方向
- 首帧或高光帧说明
- 干净画面正负向词

不要把 24 或 48 个镜头塞进同一张最终生图，除非用户明确要故事板总览。最终制作更推荐分开生图，避免黑线、脏边和文字污染。

## 黑白轨迹分镜图规范

黑白轨迹分镜图负责视频执行路线，不负责成片画风。

必须写：

- 黑白灰信息图、简单镜头框、角色编号、运动箭头、镜头箭头、攻击路径、特效路径。
- 一个普通镜头可用 2-3 个轨迹小图；复杂打斗镜头可用 10-20 个轨迹小图。
- 只保留必要编号和方向标注，不要成片式彩色厚涂，不要复杂排线，不要把它当角色或场景参考图。

默认输出时，黑白轨迹分镜图应单独放入 `11_黑白轨迹分镜总览` 或对应轨迹目录，避免和角色图、场景图混用。

## 关键参考图规范

关键参考图用于视频生成的稳定参考，不是完整分镜表。

优先生成：

- 视频段首帧
- 角色第一次出场帧
- 角色高光动作帧
- 特效爆发帧
- 镜头尾帧
- 下一段承接帧

关键参考图要减少文字、编号、边框和分割线，避免工具把黑线学进画面。
