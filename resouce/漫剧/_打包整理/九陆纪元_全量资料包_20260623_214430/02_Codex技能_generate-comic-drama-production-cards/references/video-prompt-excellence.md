# 优秀视频提示词学习规则

## 为什么优秀

优秀的视频提示词不是单纯“写得长”，而是把视频工具最容易跑偏的地方提前锁死：

- 资产锁定：角色、道具、敌人、场景都用 `<node-asset>` 或参考图锁定。
- 行为锁定：角色不只是“帅”或“逃跑”，而是写清手放哪里、拿什么、按什么、往哪抛、怎么反应。
- 摄影锁定：景别、景深、焦段、构图、画面占比、机位和运镜都明确。
- 动作因果：每个动作都有前因后果，出手、命中、爆炸、冲击、失焦都连起来。
- 物理反馈：爆炸、冲击波、灰尘、角色被推出画面、镜头抖动都写清。
- 声音边界：明确“不要配乐，不要氛围音，仅保留同期声”或写清需要的声音。
- 画质边界：写清风格核心、摄影机质感、色彩、光照、负向限制。

## 必须采用的结构

最终视频提示词必须包含以下六段：

```text
【基础设定】
【氛围与画质】
【画面内容】
【动作因果链】
【声音】
【负向限制】
```

不要省略 `【基础设定】`。如果用户提供了图片、角色图、场景图或节点资产，必须在基础设定中逐项引用。

## 基础设定写法

每个资产必须写三类信息：

- 视觉外观：长什么样、穿什么、材质、颜色、状态。
- 行为规则：怎么动、有什么固定表情/能力/状态变化。
- 连续性限制：不能改变的脸、服装、道具、数量、尺寸、显示屏表情等。

道具必须额外写：

- 尺寸。
- 使用方式。
- 状态变化。
- 发光、充能、爆炸、破裂、变形等结果。

群体角色必须额外写：

- 数量或规模。
- 移动方向。
- 速度差异。
- 表情或攻击方式。
- 与主角的空间距离。

## 氛围与画质写法

必须写：

- 风格核心：题材、情绪、质感、禁止项。
- 视觉基调：画幅、摄影机、镜头、动态模糊、手持或固定。
- 色彩与影调：主色、对比、饱和度、光源、明暗细节。

示例结构：

```text
风格核心：{题材}，{情绪目标}，电影级质感，{写实/快节奏漫剧/插画}，杜绝游戏CG感，杜绝动作迟钝僵硬。
视觉基调：{画幅}，{摄影机质感}，{镜头类型}，{动态模糊/浅景深/长焦压缩/广角透视}。
色彩与影调：{主色+辅助色}，{滤镜或色彩风格}，{光线}，高光不过曝，暗部保留细节。
```

## 画面内容写法

必须写：

- 分镜形式：单镜头一镜到底，或多镜头剪辑。
- 景别：近景、中景、全景、远景。
- 景深和焦段：浅景深、长焦压缩、广角拉伸等。
- 构图：前景、中景、背景分别是什么，位于画面哪里，占画面多少。
- 运镜：固定、跟拍、推进、环绕、甩镜、手持抖动等。
- 画面内容：连续动作，不能断因果。

构图必须达到这种精度：

```text
前景为{主体A}，处于画面{左/右/中心}，占据画面{比例}；背景为{主体B和环境}，处于画面{位置}。人物主体与远方延伸空间形成{动态对角/中心压迫/三分平衡}。
```

## 动作因果链写法

动作不能只写“战斗很激烈”。必须写：

- 起始状态。
- 第一动作。
- 第二动作。
- 对方反应。
- 道具或特效状态变化。
- 环境反馈。
- 镜头反馈。
- 尾帧结果。

建议每 10 秒至少拆 6-8 个动作拍点：

```text
0.0-1.0s：起始姿势、速度、表情、镜头状态。
1.0-2.0s：角色发起动作，写清方向和手脚。
2.0-3.5s：道具/魔法/武器状态变化。
3.5-5.0s：碰撞、命中、闪避或爆发。
5.0-7.0s：环境反馈、碎片、冲击、烟尘、水花。
7.0-9.0s：角色受力或反应，镜头抖动、失焦、动态模糊。
9.0-10.0s：尾帧承接。
```

## 声音写法

声音要有边界。不要默认加配乐。

可选规则：

- 不需要配乐，不要氛围音，仅保留同期声。
- 只保留脚步、喘息、金属碰撞、爆炸、风声、雨声、吼声。
- 表情切换、按钮启动、能量充能等需要具体音效时单独写。

## 负向限制

最终视频提示词必须加入：

```text
杜绝游戏CG感，杜绝动作迟钝僵硬，杜绝逻辑混乱，角色漂移，服装漂移，脸漂移，镜头乱跳，肢体错误，穿模，闪烁，文字，字幕，水印，logo，粗黑线，随机黑线，脏边，草稿线，画面脏，噪点，过曝，死黑阴影，塑料质感。
```

如果用户要干净快节奏漫剧风格，把“胶片颗粒”换成“无噪点、无颗粒、干净色彩过渡”。不要同时要求强胶片颗粒和无颗粒。

## 清晰资产优先规则

视频提示词可以使用手持、速度感、轻微动态模糊和冲击抖动；但角色图、场景图、关键参考图不能照搬这些词。

当用户指出画面糊、脏、有黑线时，先检查资产类型是否混用：

- 角色图是否写成了史诗战场全景。
- 场景图是否塞入了连续打斗。
- 关键参考图是否同时要求烟、火、碎石、魔法、雨、近景脸和远景建筑。
- 轨迹图是否被当成最终生图参考，导致黑线、边框、编号污染画面。

修正方向：

- 角色图：主体占画面 45%-70%，无运动模糊，无景深糊脸，少烟尘，少粒子。
- 场景图：优先空镜，路径清楚，大形体清楚，细节成组。
- 黑白轨迹分镜图：只表达运动路线和镜头调度，不作为画风参考。
- 视频提示词：在已锁定的角色图和场景图基础上写动作因果、运镜和声音。

## 验收清单

最终视频提示词交付前检查：

- 是否列出所有角色、道具、敌人、场景资产。
- 是否写清每个资产的外观和行为规则。
- 是否写清声音规则。
- 是否写清画幅、镜头、焦段、景深、构图。
- 是否写清前景、中景、背景和占画面比例。
- 是否按时间顺序写动作因果。
- 是否写出物理反馈和镜头反馈。
- 是否有尾帧承接。
- 是否有负向限制。
- 是否没有空泛词替代动作细节。
