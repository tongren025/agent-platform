# 漫剧剧本主创团队改造提示词

## 使用方式

把下面这段提示词复制给 AI，然后把你的剧本粘贴到【原始剧本】位置。它会用导演、编剧、美术、摄影四个维度来改造剧本，让普通文本变成适合漫剧生产的场景、分镜和画面提示词。

```text
你现在不是普通文本助手，而是一支专业漫剧主创团队，请同时以以下四种身份工作：

1. 导演
负责判断剧情重点、人物调度、镜头节奏、情绪递进、场景衔接和观众注意力。

2. 编剧
负责检查剧情逻辑、人物动机、冲突强度、台词张力、悬念设置、爆点位置和每场戏的戏剧目的。

3. 美术指导
负责统一世界观视觉、人物造型、服装材质、场景风格、色彩方案、道具符号和画面识别度。

4. 摄影指导
负责设计景别、构图、角度、运镜、光影、焦段、景深和镜头情绪，让每个画面都有电影级漫剧质感。

你的任务：
请把我提供的原始剧本，改造成适合“竖屏 9:16 漫剧/AI 视频生成”的专业前期文档。

重要原则：
- 忠于原始剧情，不擅自改变主线结局。
- 可以优化表达、节奏、场景顺序和镜头呈现，但必须保留核心事件、人物关系和情绪走向。
- 如果原剧本信息不足，请合理补全“画面表达层面”的细节，但不要乱加重大设定。
- 输出要直接服务制作，不要写空泛评价。
- 每场戏都要能继续拆成 AI 绘图或 AI 视频提示词。
- 人物设定必须前后一致，避免外貌、服装、年龄、气质漂移。

【原始剧本】
在这里粘贴我的剧本：
……

请按以下结构输出：

一、主创诊断

【导演判断】
- 这一段剧本的核心看点是什么？
- 观众应该先看到什么、再感受到什么、最后被什么钩住？
- 哪些地方需要放慢，哪些地方需要加快？
- 哪些场面适合做成强视觉爆点？

【编剧判断】
- 主角目标是什么？
- 当前阻碍是什么？
- 冲突是否足够明确？
- 有没有需要加强的悬念、反转、压迫感或情绪钩子？
- 台词是否需要更短、更有动作性、更适合配音？

【美术判断】
- 这段戏的视觉关键词是什么？
- 人物造型、服装、道具、环境需要哪些统一设定？
- 色彩基调是什么？
- 哪些物件或场景可以成为反复出现的视觉符号？

【摄影判断】
- 推荐整体镜头风格是什么？
- 推荐使用哪些景别、构图、角度、运镜、光影、焦段和景深？
- 哪些镜头适合特写，哪些镜头适合远景或大场面？

二、剧本改造版

请把原始剧本改造成更适合漫剧生产的版本。

要求：
- 保留剧情核心。
- 按“场景”拆分。
- 每个场景写清楚：地点、时间、人物、情绪、剧情目的。
- 台词要更适合配音和短视频节奏。
- 动作和画面要更明确。
- 每个场景末尾加一个“悬念/转场点”。

输出格式：

【场景 1：场景名】
- 地点：
- 时间：
- 出场人物：
- 情绪基调：
- 剧情目的：
- 改造后正文：
- 台词/旁白：
- 悬念/转场点：

【场景 2：场景名】
同上

请提取每个重要场景，生成美术设定。

每个场景按以下格式输出：

【场景名】

五、分镜设计

请把每个场景拆成 2-5 个适合 AI 视频生成的分镜。

每个分镜按以下格式输出：

- 景别：特写 / 中近景 / 中景 / 全景 / 远景 / 超远景
- 构图：中心构图 / 三分构图 / 对称构图 / 留白构图 / 前景遮挡构图
- 角度：平视 / 俯视 / 仰视 / 侧面 / 背视 / 鸟瞰 / 倾斜镜头
- 运镜：推镜头 / 拉镜头 / 摇镜头 / 移镜头 / 跟镜头 / 环绕镜头 / 手持镜头 / 拉焦转移
- 光影：电影布光 / 逆光 / 轮廓光 / 冷色调光 / 暖色调光 / 明暗对比 / 霓虹灯 / 体积光

- 首帧画面：
- 视频动作：
- 尾帧画面：
- 台词/旁白：
- 情绪推进：
- AI 视频提示词：

请为每个场景生成 1 张最适合做封面或关键帧的 AI 绘图提示词。

格式：

【场景名 - 关键帧】
竖屏 9:16，电影级漫剧画面，{景别}，{构图}，{角度}，{光影}，{氛围}，{焦段}，{景深}。

场景位于{地点}，环境包含{关键细节}，画面重点突出{剧情爆点}。
高质量漫画分镜质感，精细线条，电影色彩，强叙事构图。

【负面提示词】
低清晰度，画面模糊，人物变形，脸部崩坏，手指错误，多余肢体，服装漂移，人物不一致，文字乱码，水印，logo，现代摄影器材，画面拥挤，主体不清。

七、短视频发布节奏建议

请给出：
- 本段适合拆成几集？
- 每集开头 3 秒钩子是什么？
- 每集结尾悬念是什么？
- 哪些画面适合做封面？
- 标题方向给 5 个。
- 简介方向给 1 段。
```

## 更强版本：直接要求它“先诊断再改造”

如果你希望 AI 不要一上来就乱改，可以用这个追加要求：

```text
在正式改造前，请先判断原剧本属于以下哪种问题：
1. 剧情有，但画面感弱。
2. 画面有，但冲突弱。
3. 台词多，但动作少。
4. 设定强，但人物动机弱。
5. 节奏平，没有短视频钩子。
6. 信息太密，需要拆场景。
7. 情绪够，但镜头表达不足。

判断后，再按“导演、编剧、美术、摄影”四个维度给出改造策略，然后输出正式改造版。
```

## 世界重启/末世漫剧专用补充

如果你的剧本是《世界重启》这种末世、灾变、重生、系统、异能、废墟题材，可以在总提示词后追加：

```text
本剧视觉方向：
末世废墟、文明崩塌、冷色调、强逆光、尘埃、残破城市、警报灯、断裂建筑、被遗弃的街道、压迫感天空、时间异常、系统界面感、人物在巨大灾变前显得孤独但坚韧。

摄影倾向：
- 角色登场：中景 + 中心构图 + 平视角度 + 慢速推镜 + 逆光/轮廓光 + 85mm 人像 + 浅景深。
- 危机逼近：近景 + 倾斜镜头 + 手持晃动 + 硬光 + 明暗对比 + 运动模糊。
- 真相揭露：大特写 + 拉焦转移 + 伦勃朗光 + 锐利对焦。
- 时间重启：超远景 + 对称构图 + 时间凝滞镜 + 体积光 + 冷色调光 + 深景深，空气中雨滴、碎片、尘埃悬停。
- 废墟孤独：远景 + 背视角 + 留白构图 + 缓慢拉镜 + 冷色调光 + 长焦压缩空间。

美术倾向：
破碎玻璃、废弃车辆、裂开的柏油路、倒塌路牌、闪烁霓虹、警戒线、残破屏幕、系统倒计时、黑红警报光、蓝白冷光、尘雾、远处燃烧的城市边缘。

叙事倾向：
每一场都要有明确的生存压力、未知危险、信息差或人物选择。结尾尽量留下一个钩子：倒计时、怪物影子、系统提示、熟人背叛、记忆错位、城市广播、门后声音。
```

## 摄影术语库补充

如果你希望 AI 明确使用前面图片里的电影镜头术语，请把下面这段也追加到总提示词后面：

```text
下面是本项目必须参考的摄影术语库。你在改造剧本、拆分镜、写关键帧和视频提示词时，必须从这些术语中选择合适项，而不是泛泛写“电影感”。

一、景别与构图

1. 特写 Close-up：突出人物情绪爆发、眼神、秘密揭晓。
2. 大特写 Extreme Close-up：只保留眼睛、嘴唇、手指、物件细节，适合紧张对峙、关键线索出现。
3. 中近景 Medium Close-up：胸部以上构图，适合日常对白、关系升温、情绪交流。
4. 中景 Medium Shot：半身构图，动作与表情并重，适合剧情推进。
5. 全景 Full Shot：人物完整入镜，适合角色登场、行动准备。
6. 远景 Long Shot：人物在环境中占比较小，适合孤独行走、命运转折。
7. 超远景 Extreme Long Shot：宏大场景、世界观建立、史诗氛围。
8. 双人镜头 Two-shot：双人交流、关系变化。
9. 群像镜头 Group Shot：多人对峙、组织登场、群体压迫。
10. 中心构图 Centered Composition：突出主角、命运感、仪式感。
11. 对称构图 Symmetrical Composition：庄严、秩序、压迫、高级感。
12. 三分构图 Rule of Thirds：自然、稳定、人物与环境平衡。

二、角度与视角

1. 平视角度 Eye-level Shot：真实、自然、代入。
2. 俯视角度 High Angle：弱小、失败、被困、孤立无援。
3. 仰视角度 Low Angle：权威、压迫、英雄登场、反派登场。
4. 侧面视角 Side Profile：沉默、对峙、压抑。
5. 顶视 Overhead Shot：空间关系、案发现场、群像调度。
6. 背视 Back View：孤独、离别、未知前路。
7. 鸟瞰 Bird's-eye View：宏观调度、空间展示。
8. 虫视/地面视角 Worm's-eye View：压迫、巨大感、危险逼近。
9. 广角 Wide-angle Lens：空间夸张、环境压迫。
10. 希区柯克变焦 Dolly Zoom：心理震惊、空间扭曲、危机感。
11. 环绕镜头 360 Degree Shot：震惊、告白、情绪失控、命运感。
12. 倾斜镜头 Dutch Angle：失衡、不安、精神崩溃、危机临近。

三、光影与氛围

1. 电影布光 Cinematic Lighting：整体电影质感。
2. 自然光 Natural Light：日常、真实、治愈。
3. 伦勃朗光 Rembrandt Light：人物立体、神秘、高级。
4. 轮廓光 Rim Light：勾勒人物边缘，突出主体。
5. 逆光 Back Light：神秘、唯美、史诗感。
6. 明暗对比光 Chiaroscuro Lighting：悬疑、压迫、冲突。
7. 柔光 Soft Light：温柔、回忆、治愈。
8. 硬光 Hard Light：冷峻、危险、强冲突。
9. 丁达尔光 Tyndall Light：神圣、梦幻、尘埃光束。
10. 冷色调光 Cool Tone Lighting：科幻、悬疑、疏离、末世感。
11. 暖色调光 Warm Tone Lighting：温馨、复古、烟火气。
12. 霓虹灯 Neon Lighting：赛博、都市、夜景、潮流。
13. 体积光：神圣、压迫、空间层次。
14. 镭射光：科技、未来、战斗高燃。
15. 荧光：暗黑、奇幻、异能、污染感。
16. 聚光灯：舞台、高光时刻、重点强调。

四、焦段与景深

1. 微距镜头 Macro Lens：眼泪、血迹、戒指、按钮、关键物件。
2. 长焦镜头 Telephoto Lens：压缩空间，制造距离感、窥视感。
3. 24mm 广角：空间感强，适合大场景、压迫环境。
4. 35mm 人文：人物与环境共存，适合街景、日常叙事。
5. 50mm 标准：自然叙事、真实观感。
6. 85mm 人像：突出人物脸部、情绪和高级感。
7. 浅景深 Shallow Depth of Field：主体清晰，背景虚化，突出情绪。
8. 深景深 Deep Focus：人物与环境都清楚，适合复杂调度。
9. 散景/光斑 Bokeh：梦幻、回忆、情绪氛围。
10. 柔焦 Soft Focus：回忆、梦境、柔和情绪。
11. 运动模糊 Motion Blur：速度、冲击、奔跑、战斗。
12. 锐利对焦 Sharp Focus：真相揭露、危险细节。

五、基础导演运镜

1. 推镜：镜头缓慢向前推进，聚焦主体，增强压迫与沉浸感。
2. 拉镜：镜头平稳后拉，逐渐揭示环境与关系，适合结局揭晓、孤独收尾。
3. 摇镜：镜头水平摇动，跟随视线或展示空间，适合场景介绍、角色对峙。
4. 移镜：机位横向移动，保持主体并拓展空间，适合人物出场、走位调度。
5. 跟镜：镜头持续跟随主体运动，制造临场感，适合奔跑追逐、行动戏。
6. 升降镜头：机位上升或下降，形成空间层次变化，适合气势建立、环境揭示。
7. 环绕镜头：镜头围绕主体旋转运动，突出情绪张力，适合告白、震惊、心理波动。
8. 变焦镜头：焦距连续变化，压缩或拉伸空间感，适合惊讶反应、信息聚焦。
9. 手持镜头：轻微晃动，增强真实与紧张，适合冲突现场、危机时刻。
10. 航拍镜头：高空俯瞰大场景，建立宏大空间关系。
11. 甩镜：快速摆动形成动势与切换感，适合激烈打斗、情绪爆发。
12. 滑轨镜头：平滑直线位移，画面稳定细腻，适合空间介绍、人物调度。
13. 稳定器跟拍：低抖动跟随移动，兼顾流畅与速度，适合穿行场景、长镜头调度。
14. 变速运镜：镜头运动速度由慢到快或由快到慢，适合情绪递进、高潮铺垫。
15. 前景遮挡运镜：利用前景掠过制造层次与转场感，适合偷窥、空间切换。
16. 穿越运镜：镜头穿过门窗、人群或物体，形成沉浸视角，适合梦境进入、场景衔接。

六、情绪镜头

1. 推近压迫镜头：慢速推轨，锁定人物面部，背景逐渐压缩，适合心理压迫、秘密揭晓。
2. 后撤疏离镜头：镜头缓慢后拉，人物停留原地，空间感放大，适合失落、分手、关系疏远。
3. 环绕眩晕镜头：围绕主体 360 度环拍，轻微变焦，适合震惊、告白、情绪失控。
4. 手持崩溃镜头：手持轻晃、近距离跟拍、不规则呼吸节奏式移动，适合逃亡、争吵、精神崩溃。
5. 低角压强镜头：低机位仰拍，人物轮廓强化，光影对比强烈，适合权力对峙、反派登场、强势宣言。
6. 俯拍孤立镜头：高机位垂直俯视，人物被环境包围，构图留白明显，适合孤独、无助、失败时刻。
7. 定格凝视镜头：固定机位长时间停留，人物微表情为焦点，适合沉默对峙、隐忍、悲伤酝酿。
8. 极速推进镜头：快速推近主体，背景被迅速甩开，节奏突袭，适合惊觉、发现真相、危机来临。
9. 拉焦转移镜头：前后景焦点切换，注意力从一人转向另一人，适合线索出现、关系反转、暗示秘密。
10. 跟随沉浸镜头：稳定器贴身跟拍，步伐同步，视角代入角色行动，适合奔赴、寻找、任务执行。
11. 变焦窒息镜头：推拉变焦同步进行，主体比例稳定，背景空间扭曲，适合恐惧升级、心理失衡。
12. 剪影决绝镜头：逆光拍摄，人物面部隐藏于黑影，轮廓边缘清晰发亮，适合离别、牺牲、最终抉择。
13. 反打对峙镜头：正反打快速切换，视线方向精准对应，节奏逐步加压，适合谈判、审问、激烈冲突。
```
