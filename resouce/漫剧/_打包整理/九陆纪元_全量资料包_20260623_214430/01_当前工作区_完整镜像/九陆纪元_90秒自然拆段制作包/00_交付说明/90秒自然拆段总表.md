# 《九陆纪元》开场 90 秒自然拆段总表

## 拆段原则

本拆分不按机械 10 秒切割，而按自然转场点、动作闭环、情绪落点和视频生成可控性切割。

- 单段上限：15 秒以内。
- 目标长度：约 5-12 秒为主。
- 打斗段按“起势 -> 攻防 -> 受力 -> 落点”切。
- 魔法段按“聚能 -> 展开 -> 释放 -> 命中/抵消 -> 余波”切。
- 悬念段允许在“一厘米”位置切，但必须是有意设计。
- 不在半招、半句台词、半次爆炸、半次救场中间切。

## V001 巨龙压场与艾拉真打

视频段ID：V001  
建议时长：8 秒  
实际可浮动范围：7-9 秒  
对应镜头：01-06  
场景：史诗战场（虚假）/ 黄昏  
出场角色：艾拉、巨龙

起点：超远景低角度，巨龙翼展遮住黄昏天空，艾拉站在断柱顶端。  
终点：龙爪砸下，艾拉半跪滑退，蓝色护盾阵挡住碎石和冲击。  
为什么在这里切：这是一次完整魔法攻防闭环，从龙焰蓄力、艾拉闪避、反击，到护盾挡爪结束。  
不能再提前切的原因：如果切在龙焰或魔法反击中间，观众会看不清艾拉确实能和巨龙过招。  
下一段承接：战斗刚停一瞬，苍霖从竞技场入口出现。

制作重点：
- 蓝白星环对赤金龙焰。
- 艾拉必须是主动战斗的魔法师，不是站桩角色。
- 巨龙压迫感要强，反转才成立。

## V002 苍霖入场与苹果反转

视频段ID：V002  
建议时长：12 秒  
实际可浮动范围：10-13 秒  
对应镜头：07-18  
场景：史诗战场（虚假）/ 黄昏  
出场角色：苍霖（开场形态）、艾拉、巨龙

起点：苍霖站在竞技场拱门阴影里，手指轻碰腰间苹果。  
终点：巨龙趴在废墟里委屈等第二个苹果，竞技场碎成玻璃片，硬切雨夜废土巷道。  
为什么在这里切：这是一个完整喜剧反转闭环：男主入场 -> 战斗停顿 -> 咬苹果 -> 抛苹果 -> 巨龙扑食 -> 艾拉吐槽 -> 硬切过去。  
不能再提前切的原因：苹果反转必须完整展示，否则观众只会觉得男主突然出现、巨龙突然变蠢。  
下一段承接：三个月前，雨夜废土巷道，弱小苍霖靠墙濒死。

制作重点：
- 苍霖开胸龙族废墟装要帅、野、懒。
- 巨龙从威严变馋的眼神要清楚。
- 硬切转场要像世界碎片/玻璃碎片，不要软淡化。

## V003 雨巷第一轮求生反击

视频段ID：V003  
建议时长：11 秒  
实际可浮动范围：9-12 秒  
对应镜头：19-23  
场景：废土街巷 / 暴雨 / 三个月前  
出场角色：弱小苍霖、暴徒甲、暴徒乙、暴徒丙

起点：苍霖赤脚靠墙，上身无衣，脏绷带斜缠肩胸，雨水流过伤痕和肋骨。  
终点：苍霖抓起泥水和碎玻璃按进暴徒甲脸上，夺下钢筋但身体几乎被重量带倒。  
为什么在这里切：这是第一轮完整求生动作：三人逼近 -> 甲出手 -> 苍霖硬扛失败 -> 头槌 -> 环境反击。  
不能再提前切的原因：如果只切到头槌，会显得苍霖突然很能打；必须接上泥玻璃糊脸，体现他是靠环境求活。  
下一段承接：乙丙从两侧压上，苍霖短暂得手后重新陷入包围。

制作重点：
- 苍霖弱小形态必须赤脚、上身无衣、伤痕明显。
- 暴徒三人外形要和苍霖明显不同。
- 动作要脏、短、求生，不要拍成潇洒武打。

## V004 乙丙围攻与重新陷入死局

视频段ID：V004  
建议时长：11 秒  
实际可浮动范围：10-12 秒  
对应镜头：24-30  
场景：废土街巷 / 暴雨  
出场角色：弱小苍霖、暴徒甲、暴徒乙、暴徒丙

起点：乙和丙从两侧压来，苍霖跪在水里，握钢筋的手发抖。  
终点：三名暴徒重新站起，苍霖跪在三人中间，膝盖一软又跪回水里。  
为什么在这里切：这是第二轮完整围攻闭环：被包围 -> 滑倒躲拳 -> 借势扫腿 -> 被丙撞墙 -> 泥地缠斗 -> 三人重新围上。  
不能再提前切的原因：丙撞墙和泥地缠斗必须连在一起，才能把“短暂反击”重新压成“必死局”。  
下一段承接：暴徒甲抓住苍霖，把钢筋抵到喉前一厘米。

制作重点：
- 苍霖每次反击都要付代价。
- 滑倒不是帅气闪避，是狼狈失衡。
- 最后俯拍三角围困，压出无路可走。

## V005 死亡一厘米与世界树启动

视频段ID：V005  
建议时长：10 秒  
实际可浮动范围：9-11 秒  
对应镜头：31-35  
场景：废土街巷 -> 世界树崩塌宏观景  
出场角色：弱小苍霖、三名暴徒、世界树异象

起点：暴徒甲抓住苍霖脖颈，把他按在锈车残骸上，钢筋尖抵到喉前一厘米。  
终点：暗金丝线像倒流流星雨坠入废土城市，远处建筑被金光照亮。  
为什么在这里切：这是“观众以为主角快死了 -> 世界级异象突然出现”的悬念启动闭环。  
不能再提前切的原因：世界树必须在死亡威胁压满之后出现，否则不会形成“是不是天命救场”的期待。  
下一段承接：光丝落回巷子，苍霖伸手，观众以为觉醒即将发生。

制作重点：
- 钢筋喉前一厘米是死亡钩子。
- 世界树不是普通裂缝，要有浮空大陆、树根网络、发光丝线。
- 这一段结尾不要救人，只制造期待。

## V006 天选错觉被掐灭

视频段ID：V006  
建议时长：11 秒  
实际可浮动范围：10-12 秒  
对应镜头：36-41  
场景：废土街巷 / 世界树光雨  
出场角色：弱小苍霖、三名暴徒

起点：光丝落进巷子，苍霖和三名暴徒都停住。  
终点：暴徒甲再次举起钢筋，乙丙在后方压住退路，苍霖半躺在水里几乎爬不起来。  
为什么在这里切：这是完整反套路闭环：光丝到指尖 -> 暴徒掐灭天命 -> 台词嘲讽 -> 一拳打回现实 -> 没有觉醒 -> 最后一刺。  
不能再提前切的原因：如果切在光丝到指尖，会变成真觉醒预告；必须接上掐灭和没有觉醒，才能完成套路粉碎。  
下一段承接：钢筋落下前，甲脚下水洼悄悄开出蓝色魔法阵。

制作重点：
- 光丝停在指尖一厘米，和钢筋喉前一厘米呼应。
- 暴徒甲掐灭光丝要粗暴，像掐烟。
- “你以为你是天选之人？”是本段唯一台词重音。

## V007 艾拉雨水空间术救场

视频段ID：V007  
建议时长：11 秒  
实际可浮动范围：9-12 秒  
对应镜头：42-46  
场景：废土街巷 / 暴雨  
出场角色：艾拉、弱小苍霖、三名暴徒

起点：暴徒甲脚下水洼浮出蓝色魔法阵，雨滴悬停成圆。  
终点：艾拉从水洼倒影中跨到苍霖身边，用铁管轻点甲太阳穴，蓝色环形冲击炸开，甲倒下。  
为什么在这里切：这是一次完整救场闭环：先出手后现身 -> 偏移处刑线 -> 雨滴锁住乙丙 -> 近身收束。  
不能再提前切的原因：艾拉救场不能只出现人，必须完整展示她的魔法师控场方式。  
下一段承接：艾拉扶起苍霖，从雨巷撤离，进入龙骨地裂。

制作重点：
- 艾拉是魔法师救场，不是普通拿铁管敲人。
- 水洼、雨滴、铁管都是施法媒介。
- 她的表情必须冷，救人像处理麻烦。

## V008 撤离、龙骨深渊与龙蛋破壳

视频段ID：V008  
建议时长：11 秒  
实际可浮动范围：10-13 秒  
对应镜头：47-48，吸收原洞穴段细节  
场景：雨巷 -> 龙骨地裂 -> 龙骨深渊  
出场角色：艾拉、弱小苍霖、母龙尸体、龙蛋

起点：艾拉把苍霖手臂搭在肩上，半拖半扶穿过雨巷。  
终点：裂纹龙蛋里暗金微光涌出，湿漉漉的小爪子破壳伸出，画面黑屏。  
为什么在这里切：这是“逃离死亡 -> 进入死亡遗迹 -> 看见新生命”的完整钩子闭环。  
不能再提前切的原因：如果只到地裂或母龙尸体，结尾钩子不够；必须让龙蛋破壳出现。  
下一段承接：黑屏后 LOGO 砸入。

制作重点：
- 龙骨肋骨拱门要像巨大生物遗骸，不只是普通山洞。
- 母龙尸体、机械鱼叉、锈链、黑色冻结龙血必须看清。
- 龙蛋裂纹暗金光是整段生命钩子。

## V009 LOGO 片名砸入

视频段ID：V009  
建议时长：5 秒  
实际可浮动范围：4-6 秒  
对应镜头：LOGO  
场景：黑底  
出场元素：《九陆纪元》片名

起点：黑屏静默，承接龙蛋破壳。  
终点：重工业铆接金属质感字体《九陆纪元》定格，暗金粒子流线熄灭。  
为什么在这里切：LOGO 是独立收束段，不应该和龙蛋破壳混在同一个生成段里。  
不能再提前切的原因：龙蛋破壳需要前一段留出静默冲击，LOGO 需要单独节奏。  
下一段承接：进入正片或下一集开场。

制作重点：
- 黑底，不要复杂背景。
- 字体质感：刮痕、锈迹、干涸血迹、火星、冲击波纹理。
- 粒子要暗金，不要花哨彩虹色。

## 后续制作顺序建议

1. 先做 V001、V002：它们决定开场吸引力和反转。
2. 再做 V005、V006：它们决定世界树悬念和反套路记忆点。
3. 再做 V007：艾拉救场必须足够惊艳。
4. V008 要单独做关键参考图：龙骨深渊、母龙尸体、龙蛋破壳。
5. V009 可最后做，避免 LOGO 风格提前限制正片画面。
