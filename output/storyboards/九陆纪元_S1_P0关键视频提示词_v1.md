# 《九陆纪元》S1 P0 关键视频提示词 v1

> 用途：用四段关键视频先验证“场景是否抓人”。
> 原则：每段 4-6 秒，只做一个动作和一个运镜。提示词以 Seedance / 图生视频友好格式书写。

## 全局视频规则

```text
竖屏9:16，电影质感，干净半写实东方幻想漫剧插画，角色面部一致，服装不漂移，画面稳定，动作自然，光影清晰，无文字水印。
每段只保留一个运镜，运镜和角色动作分开描述。
不要使用高速、快速、剧烈、夸张等词。需要表达紧张时，用急切、压迫、骤然、短促、失重、风声增强等描述。
```

## EP02《假觉醒》关键视频

**素材建议**：使用 EP02 主视觉作为首帧。

**时长**：6 秒。

**视频提示词**

```text
【素材】EP02 主视觉：废矿广场，世界树残根中央，R3苍霖手按树根，金色世界树光丝刚从他掌心升起。

【镜头】中近景低角度，苍霖位于画面下方，世界树残根向上压迫，人群是背景模糊黑影。

【角色动作】苍霖的手指微微收紧，脸上出现短暂的不可置信；金色光丝从他掌心升起后在半空停顿一拍，随后偏转离开他，飞向画面右上方。金光离开后，苍霖脸上的亮度慢慢退掉，只剩胸口龙骨碎片的微弱蓝白光。

【运镜】缓慢推进 dolly in，从苍霖手掌推到他的脸。

【光影】金光升起时全场短暂变亮，金光离开后画面重新落入废矿阴影。苍霖脸一半残留暖金，一半变暗。胸口蓝白碎片光极弱，不抢主光。

【音频】环境嘲笑声先被抽空，只剩一声心跳；金光离开后嘲笑声闷闷地回来。苍霖低声台词：也是。

【全局】竖屏9:16，电影质感，干净半写实东方幻想漫剧插画，角色一致，面部清晰，服装不漂移，画面稳定，无文字水印。
```

**验收**

- 观众必须看懂：光不是没来，是来了又走。
- 苍霖不能大幅表演，只能短暂愣住后空掉。
- 台词“也是”要轻，不要喊。

## EP06《数据残留》关键视频

**素材建议**：使用 EP06 主视觉作为首帧。

**时长**：6 秒。

**视频提示词**

```text
【素材】EP06 主视觉：深夜矿洞，R3苍霖抱着发抖的小龙，胸口龙骨碎片投出破碎蓝色全息少女。

【镜头】近景，苍霖和小龙在画面下方偏右，全息少女在画面上方中央，矿洞背景黑暗。

【角色动作】小龙胸腔白热光紊乱明灭，爪子抓住苍霖手腕；苍霖缓慢抬头看向全息少女，眼神从惊醒变成不安。全息少女的半张脸断续闪烁，黑色数据块一点点吞掉她的嘴和眼角，她向镜头伸手但手指碎成蓝色方块。

【运镜】缓慢推进 dolly in，从苍霖和小龙推向全息少女。

【光影】暖橙矿灯很弱，蓝色全息光照亮苍霖脸和小龙鳞片。全息损坏时蓝光短促闪烁，矿洞边缘保持暗。

【音频】电流断续声，远处滴水声，小龙细小哀鸣。全息女声断续：如果有人能收到……我不是病毒……他们删了我的……

【全局】竖屏9:16，电影质感，干净半写实东方幻想漫剧插画，角色一致，面部清晰，服装不漂移，画面稳定，无文字水印。
```

**验收**

- 全息影像要像一个人正在被删除，不是普通投影讲设定。
- 小龙必须参与，不要让它静止像道具。
- 蓝光闪烁要控制，不能糊成一团。

## EP07《世界树信号》关键视频

**素材建议**：使用 EP07 主视觉作为首帧。

**时长**：6 秒。

**视频提示词**

```text
【素材】EP07 主视觉：世界树根部遗迹，R3苍霖手贴黑色世界树根，九大陆坏死幻象围绕他展开。

【镜头】远景到中景，苍霖很小，九个大陆幻象巨大，黑色世界树根从地面和岩壁伸向画面四周。

【角色动作】苍霖手贴黑根，身体微微后仰，像被信息冲击到站不稳；手背蓝白血管光一闪一闪。九个大陆幻象按顺序短促亮起：机械穹顶坠落、星环城断裂、海倒灌、巨神睁眼、灯火熄灭、冰下人影睁眼、归墟坑扩张、光树变黑、龙骨开裂。

【运镜】缓慢环绕 orbit，围着苍霖转半圈，让九大陆幻象像审判环一样压下来。

【光影】背景极暗，黑根裂缝透出白热光，九大陆幻象是冷蓝白碎片光。每个幻象亮起时短暂照亮苍霖侧脸，随后熄灭。

【音频】低频世界树轰鸣，每个大陆幻象亮起时对应一声不同质感的崩裂音。苍霖急促呼吸，最后说：不是我们的事。

【全局】竖屏9:16，电影质感，干净半写实东方幻想漫剧插画，角色一致，面部清晰，服装不漂移，画面稳定，无文字水印。
```

**验收**

- 苍霖要显得小，世界要显得大。
- 九大陆不是地图展示，而是灾难闪回。
- 最后一句“不是我们的事”要虚，像在骗自己。

## EP09《第一次飞》关键视频

**素材建议**：使用 EP09 主视觉作为尾帧或目标帧。如果工具支持首尾帧，首帧用悬崖坠落，尾帧用龙翼展开。

**时长**：6 秒。

**视频提示词**

```text
【素材】EP09 主视觉：云海上方，成长少龙展开双翼，R3苍霖伏在龙背上抬头，阳光穿透翼膜。

【镜头】从坠落中的近景转为云海上方的超宽奇观。龙和苍霖从画面上方坠入云雾，随后龙翼展开撑满画面。

【角色动作】苍霖一开始死死抱住龙颈，头发和旧披风被风压向后；龙身体下坠三秒，翼膜收紧。接近云层时，龙猛地展开双翼，翼尖划开云雾。苍霖在风声变柔后慢慢抬头，眼神从恐惧变成劫后余生的自由。

【运镜】跟随下坠 falling follow，然后在龙翼展开瞬间缓慢拉远 reveal。

【光影】前半段云雾偏暗，风压强；后半段阳光从右上方穿透半透明翼膜，翼膜血管发亮，云海出现金色边缘光。远处九大陆轮廓很淡，只做尾钩。

【音频】前半段风声尖啸，心跳密集；龙翼展开后风声变开阔，音乐释放。苍霖短促吸气，不说大段台词。

【全局】竖屏9:16，电影质感，干净半写实东方幻想漫剧插画，角色一致，面部清晰，服装不漂移，画面稳定，无文字水印。
```

**验收**

- 一定要先坠落再飞，不能开场就飞。
- 龙翼展开瞬间是最贵的画面，不要被追兵或台词抢戏。
- 苍霖要有怕，但最后不退。

## 四段测试的通过标准

| 集数 | 通过标准 | 失败表现 |
|---|---|---|
| EP02 | 6 秒内看懂“希望离开他” | 只是普通发光或觉醒 |
| EP06 | 看懂“有人在被删除并求救” | 像普通通讯投影 |
| EP07 | 看懂“九陆都在坏死” | 像展示地图或风景 |
| EP09 | 感到“坠落后释放” | 普通骑龙飞行 |

## 下一轮扩展方式

通过四段关键视频后，再按同一格式扩展每集完整镜头：

1. EP02 扩展 S01-S07。
2. EP06 扩展 S01-S07。
3. EP07 扩展 S01-S08。
4. EP09 扩展 S01-S08。

每段视频提示词只从对应详细分镜里取一个动作，不要把整集剧情塞进单段。
