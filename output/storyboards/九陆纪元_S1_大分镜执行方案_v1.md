# 《九陆纪元》S1 大分镜执行方案 v1

> 目标：把“场景”从背景名词，改成能让观众停住的视觉事件。
> 当前建议按 10 集入口篇执行：每集 25-40 秒，竖屏 9:16，单集只抓一个主情绪和一个强主画面。

## 总判断

现在的问题不是世界观不够，而是部分集数只有“信息推进”，缺少“能被观众秒懂的画面锚”。

短剧观众不会因为“矿洞 / 废巷 / 世界树”留下来，会因为下面这些留下来：

- 他以为自己被选中了，下一秒光从他身上移开。
- 全世界都嫌他脏，刚出生的小龙把头拱进他怀里。
- 深夜收到一个被删除的女孩求救信号。
- 他嘴上说“不是我们的事”，手却在抖。
- 他从悬崖掉下去三秒，龙翼才打开。

所以每集都要有一个“截图级主画面”，其余场景只服务这个画面。

## 全季大走向

```text
EP01 被人踩：人不选他
EP02 被命运拒：天也不选他
EP03 被冷救：有人救他，但不是因为爱
EP04 被需要：小龙选了他
EP05 会笑了：他第一次有日常
EP06 听见求救：世界开始把伤口递给他
EP07 看见坏死：他知道这不是自己的小事
EP08 告别：他真正离开泥地
EP09 起飞：压抑情绪总释放
EP10 看见九陆：从“我活下去”变成“世界好大，我来了”
```

## 分镜原则

1. 前 3 秒不给设定，先给情绪或奇观。
2. 每集只讲一个观众问题：这集到底戳哪种痛。
3. 每集至少一个反转：以为 A，其实 B。
4. 每集结尾必须留下一个动作未完成、秘密未解释、关系未稳定。
5. 同一场景不能只是换背景，必须换情绪功能：废巷可以是挨打、喂苹果、告别，但每次观众感受必须不同。

## EP01《微光 / 泥里的人》

**观众问题**：被踩到泥里时，你会不会还伸手捡回自己的东西？

**主画面**：苍霖趴在龙骨废巷的泥水里，暴徒离开，手指一点点摸到被踩灭的龙骨碎片。

**3 秒钩子**：拳头从画面上方砸下，苍霖没有躲，双臂死死护胸。

**关键镜头**

1. 近景低角度：拳头砸脸，血溅到胸口布条。
2. 远景俯拍：三人围住苍霖，废巷远处龙骨像山一样压着天空。
3. 微距：碎片滚出，蓝白血管纹跳两次。
4. 中景仰拍：靴底踩下，蓝光从鞋缝挤出又灭。
5. 特写：苍霖眼里的光跟着灭。
6. 大特写：他重新握住碎片，指缝一闪。
7. 尾钩：暴徒走远，靴底冒出蓝白烟。

**不能平的点**：不要把暴徒拍成普通欺负，要拍成“整个城市规则在踩他”。废巷要像审判场。

## EP02《假觉醒》

**观众问题**：你有没有以为终于轮到你了，结果那道光只是路过？

**主画面**：世界树金光扫到苍霖掌心，全场安静一秒，随后金光离开，只剩胸口碎片的蓝光尴尬地亮着。

**3 秒钩子**：测试广场上，一个少年被金光托起离开废矿，镜头切到苍霖站在人群最后。

**关键镜头**

1. 全景：废矿广场，世界树残根像审判机器。
2. 中景：骆刑停在苍霖面前，挡住他的路。
3. 特写：苍霖把手按上树根，指尖发抖。
4. 奇观镜头：金光突然亮起，全场静音。
5. 反转镜头：金光像识别错误一样从他手上撤走。
6. 特写：苍霖低声说“也是”，没有哭也没有怒。
7. 尾钩：屋檐阴影里，艾拉没有看树根，看的是他胸口碎片。

**重做重点**：这集必须狠。不是“测试失败”，而是“希望被命运亲手拿走”。场景要有仪式感，像公开处刑。

## EP03《星蓝的手》

**观众问题**：真正救你的人，可能并不温柔。

**主画面**：雨停在半空，艾拉星环展开，苍霖满嘴血咬着碎片，骆刑的靴子停在他头顶前一寸。

**3 秒钩子**：矿卫掰开苍霖手指，第三根被掰开时，碎片烫穿对方手腕。

**关键镜头**

1. 暗夜矿坑：矿卫拖着苍霖，脚在泥里划出血线。
2. 特写：苍霖把碎片主动翻过来，按上矿卫手腕。
3. 中景：蓝白灼痕炸开，矿卫惨叫松手。
4. 慢镜：雨滴悬停，星环从黑暗里展开。
5. 艾拉登场：法杖点地，声音冷淡：“他还不能死。”
6. 矿洞内：艾拉止血，发现碎片不烫苍霖。
7. 尾钩：矿洞深处传来蛋壳心跳，频率和苍霖一致。

**不能平的点**：艾拉不是温柔救命恩人，她是冷工具人先救命。冷感越足，后面关系增长越有空间。

## EP04《龙蛋》

**观众问题**：如果全世界都不要你，一个刚出生的生命却把你当成全世界。

**主画面**：灰白死蛋在苍霖伤手下裂开，一只湿漉漉的小爪抓住他的手指。

**3 秒钩子**：骆刑用铁钩撬蛋，蛋纹丝不动，镜头切到苍霖胸口碎片发烫。

**关键镜头**

1. 矿洞深处全景：世界树黑根缠住灰白龙蛋。
2. 工具撬蛋：矿卫轮流失败，声音刺耳。
3. 骆刑逼苍霖上前：“罪人家的血，试试。”
4. 特写：苍霖手掌贴上蛋壳，他自己先闭眼，怕再被笑。
5. 静音一拍：蛋壳里响起心跳。
6. 奇观镜头：死纹褪去，白热光从裂缝漏出。
7. 尾钩：小爪抓住苍霖，镜头给苍霖第一次不知所措的表情。

**重做重点**：龙蛋不要拍成普通孵化，要拍成“别人撬不开，只有他碰一下就活”。这是全季情绪反转核心。

## EP05《苹果》

**观众问题**：人活着有时不是为了大事，是为了有人等你切下一块苹果。

**主画面**：废巷黄昏，小龙扑苹果摔进破布堆，苍霖忍不住笑了。

**3 秒钩子**：小龙从画面外扑出，叼苹果失败，撞翻破桶。

**关键镜头**

1. 轻喜剧开场：小龙扑苹果，翅膀太小，扑空。
2. 特写：苍霖切苹果，动作笨但很认真。
3. 小龙小口啃皮，啃完抬头等下一块。
4. 苍霖第一次笑，说：“就你吃得讲究。”
5. 情绪降温：苍霖把最后一块苹果留给小龙，自己没吃。
6. 暗线：远处世界树光明显比 EP01 暗。
7. 尾钩：小龙突然抬头，看向没人看的天空。

**不能平的点**：轻喜剧不是水集。它负责让观众爱上“一人一龙”的日常，否则后面出发没有情感重量。

## EP06《数据残留》

**观众问题**：深夜收到求救信号，你能不能装作没听见？

**主画面**：矿洞夜里，碎片投出破碎蓝色全息影像，一个机械鸟女孩的脸断断续续出现：“我不是病毒……他们删了我的……”

**3 秒钩子**：小龙睡着时突然抽搐，胸腔白热光疯狂明灭。

**关键镜头**

1. 夜景：矿洞只剩矿灯和世界树微光。
2. 小龙噩梦：爪子在石面乱刨，像在逃。
3. 碎片共振：苍霖抱住小龙，胸口碎片贴上白热焰心。
4. 数据奇观：破碎方块、青色羽片、机械鸟眼睛、女孩半张脸。
5. 信息断裂：“如果有人能收到……我不是病毒……”
6. 苍霖和小龙对视：两个人都醒着。
7. 尾钩：艾拉认出其中一帧是星圣陆北城。

**重做重点**：这集不能只是“看到信号”，要拍成恐怖感和求救感。观众要觉得苍霖听见了一个真正的人。

## EP07《世界树信号》

**观众问题**：当你看见更大的东西正在崩塌，还能说“不关我事”吗？

**主画面**：苍霖触碰黑化世界树根，九大陆坏死影像像碎玻璃一样围绕他展开。

**3 秒钩子**：世界树根部突然熄灭一大片，整座废矿同时暗了一秒。

**关键镜头**

1. 遗迹全景：黑根像血管一样插进岩壁。
2. 苍霖伸手：不是英雄姿态，是害怕但还是碰。
3. 九段闪回：青霄机械穹顶坠落、星圣浮空城断裂、潮生海倒灌、无昼灯灭、冰封人影睁眼等。
4. 回到现实：苍霖后退，喘不过气。
5. 他对小龙说：“不是我们的事。”
6. 停三秒：他的手一直在抖。
7. 尾钩：小龙低鸣，黑根深处传来回应。

**重做重点**：这集是世界观第一次真正变大。不要用解释，必须用九个 1 秒视觉锤。

## EP08《选择》

**观众问题**：离开最难的不是走，是跟那个劝你别走的人告别。

**主画面**：矿洞口黄昏，老矿工坐在废轨边，苍霖背着破包，小龙站在身后，两人都看着同一片荒地。

**3 秒钩子**：通缉令贴满废巷，画上的苍霖被写成“龙灾携带者”。

**关键镜头**

1. 废巷：苍霖撕下一张通缉令，发现每面墙都有。
2. 收拾东西：苹果核、碎片绳、破毯子，都是前面情感物。
3. 老矿工出现：“外面什么都没有。”
4. 苍霖：“这里也是。”
5. 老矿工沉默，最后笑了一下：“也是。”
6. 远景：苍霖和小龙走出矿洞口，身影变小。
7. 尾钩：老矿工看着他们背影，摸出一枚旧龙鳞。

**不能平的点**：这集不能只是“决定出发”。要加入通缉压力和旧物告别，否则情绪会软。

## EP09《第一次飞》

**观众问题**：自由不是不怕，是掉下去之后终于相信自己能展开翅膀。

**主画面**：龙从悬崖自由落体三秒，云海逼近，最后一刻龙翼在太阳下展开，苍霖头发和翼膜被光打透。

**3 秒钩子**：追兵到悬崖边，前路断了，苍霖低头看万丈云海。

**关键镜头**

1. 悬崖全景：前方断崖，后方火把追来。
2. 苍霖翻上龙背，小龙已经长到可骑但还不稳。
3. 龙回头看他，像在问“你确定？”
4. 苍霖拍龙脖子：“走吧。”
5. 三秒坠落：风声尖啸，画面失重，苍霖死死抱住龙颈。
6. 翼展开：风声从尖变柔，阳光穿过翼膜。
7. 尾钩：云海之上，远处浮现九大陆第一道轮廓。

**重做重点**：这集必须做成全季壁纸帧。不要省预算，不要用普通飞行动画糊过去。

## EP10《九陆》

**观众问题**：第一次看见世界这么大，你会怕，也会想去。

**主画面**：云海上方，九大陆从雾里依次露出，每块大陆都有一个陌生人抬头。

**3 秒钩子**：苍霖和龙冲破云层，原本以为是天空，结果是更大的大陆群。

**关键镜头**

1. 云海开场：龙背上的苍霖第一次安静下来。
2. 第一大陆：烬龙陆在身后变小。
3. 青霄陆：机械穹顶中，清音的数据残影抬头。
4. 星圣陆：艾拉故乡北城废墟一闪。
5. 潮生、巨神、无昼、冰封、归墟、神国逐一给 1-2 秒识别画面。
6. 苍霖看着前方，说：“好大。”
7. 季终钩子：九大陆中央的世界树主干是黑的。

**不能平的点**：这集不要解释设定。它是 S2 预告片，靠奇观和“世界好大”的情绪收束。

## 重做优先级

### P0 必须重做或强化

- **EP02 假觉醒**：当前只要拍成普通测试失败，就会平。必须做出“命运先给希望再撤走”的羞辱感。
- **EP06 数据残留**：这是从日常进入大世界的门。如果只是投影说明，会很像设定讲解。必须像深夜求救。
- **EP07 世界树信号**：九大陆闪回必须有视觉锤，否则观众不信世界真的在坏。
- **EP09 第一次飞**：全季情绪总释放，必须是最贵、最漂亮、最能截图传播的一集。

### P1 建议增强

- **EP05 苹果**：轻喜剧动作要具体，别只拍温馨。
- **EP08 选择**：加入通缉令、旧物、老矿工旧龙鳞，让“走”有代价。

### P2 可保持

- **EP01** 已经有强钩子，重点是压迫感和碎片光。
- **EP03** 人物关系清楚，重点是艾拉冷感。
- **EP04** 核心成立，重点是龙蛋“别人撬不开、他一碰就活”。
- **EP10** 方向成立，关键是别用台词解释。

## 场景重构清单

| 场景 | 不要这样拍 | 应该这样拍 |
|---|---|---|
| 废巷 | 破房子背景 | 城市规则踩人的审判场 / 后来变成一人一龙日常 / 最后变成告别地 |
| 世界树残根 | 发光树根设定 | 会识别、会拒绝、会坏死的命运机器 |
| 矿洞 | 躲藏地点 | 暂时的家 / 龙蛋产房 / 深夜信号接收站 |
| 矿洞口 | 转场点 | 艾拉救场入口 / 离开旧世界的门 |
| 悬崖 | 飞行起点 | 生死选择：后面是追兵，前面是坠落 |
| 云海九陆 | 地图展示 | 世界第一次变大，S2 所有欲望从这里打开 |

## 下一步建议

下一步不要直接全季细化。先挑 P0 的四集做“每集 6-8 镜头可生成分镜”：

1. EP02《假觉醒》
2. EP06《数据残留》
3. EP07《世界树信号》
4. EP09《第一次飞》

这四集决定观众会不会觉得“场景有东西”。如果这四集立住，其他集数只是补强。
